字幕工作室

版本 2.3.5 · 作者邮箱 weieouer@gmail.com

未经授权不得商用。

  1. 导入选择音视频提取字幕，或导入 SRT；模型按需下载。
  2. 处理有剧本时：校验差异 → 校准文字 → 对齐时间。
  3. 复核点击字幕定位播放，修改文字和时间；微调先预览，再应用。
  4. 保存“保存工程”方便继续编辑；“导出”生成 SRT / MKV，位置自选。

标签　蓝色为自动完成，绿色为文字确认；黄／红色需复核，文字确认不代表时间正确。勾选和标签不改变导出标记。

快捷键　空格 播放／暂停 · Ctrl+S 保存
Ctrl+Z 撤销 · Ctrl+Y 重做 · Ctrl+F 搜索

更多说明：将鼠标停在按钮或参数上。
