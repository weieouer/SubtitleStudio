# SubtitleStudio · 字幕工作室

把成片音频与剧本对白对齐，或直接从人声提取字幕，生成可直接导入剪映的 SRT 字幕。

全程本地运行，素材不上传。字幕对齐时文字以剧本为准、时间以音频为准；字幕提取时文字和时间都来自本机语音识别，每个识别段落完整输出为一条字幕。

## 设计原则

- **两种处理方式。** 字幕对齐需要成片和剧本，文字以剧本为准、时间以人声为准；字幕提取只需要成片，每个识别到的人声段落完整输出为一条字幕，不再按单行字数拆分，适合没有剧本的素材。
- **对齐模式的文字来自剧本。** 语音识别只提供字级时间戳，识别出的谐音错字不会进入字幕；提取模式的文字来自本地识别结果。
- **字幕只留纯台词。** 最终文字只保留汉字、字母和数字；标点、符号、空格、换行都只作为断句间隔，不进入字幕。
- **表演提示不进字幕。** 台词中的「（失声）」「【大喊】」等括号内容会剔除，只保留真正说出口的词。
- **内心独白统一输出。** 带 `（OS）` 的独白属于台词，和普通对白一样生成字幕；界面暂不提供关闭开关。
- **语气词不进字幕。** 句尾的「呀、啊、哎」等会去掉；整条只有语气词时不生成字幕。「吗、呢、吧」这类承担疑问或祈使语气的助词保留。
- **不给人声以外的内容配字幕。** 对齐模式下，没有剧本对应的识别片段会被剔除；提取模式下依赖人声检测，并剔除 `（音乐）`、`【音效】` 这类括号提示，咳嗽、环境声不会主动生成字幕。
- **对齐按完整词分段，提取按整段输出。** 字幕对齐时单行字数只是上限，不会为了凑上限把「一起」「怎么」这类完整的词从中间切开；字幕提取则保留识别片段的完整一段，不再拆成多条。
- **对齐在停顿处断句。** 标点、角色换句、以及「那个，这个，怎么说呢」这类自然的犹豫停顿都会优先断开；同一句内默认首尾相接，但停顿处保留真实间隙。字幕提取不额外拆分停顿。
- **开口即显示，收尾略留一点。** 字幕对齐时，默认起点严格贴在第一个真正发声的字上，结尾做约 0.18 秒的轻微延音；需要时可以调整「整体提前」和「句尾延音」。字幕提取不做整体偏移或延音，严格使用识别段落的时间。

## 环境要求

- Windows 10 / 11
- Python 3.11 及以上（工程内已带 `.venv`）
- 首次识别需要语音模型：`small` 约 500MB。安装包和源码版都不内置，在界面里点击「下载」后保存在 `data/models/`
- 可选：NVIDIA 显卡 + CUDA 运行库，用于 GPU 加速

当前机器只缓存了完整的 `small`（约 500MB）模型，断网也能直接使用，加载时不发起任何网络请求。`medium`（约 1.5GB）和 `large-v3`（约 3GB）尚未缓存；只有在你点击对应模型状态条右侧的「下载」后，才会开始联网：优先从 ModelScope 国内源下载，失败时自动回退到 `hf-mirror.com`，文件保存在 `data/models/`。选择模型、点击「开始处理」或加载模型都不会自动联网。模型未下载时，开始按钮保持禁用，后端也会拒绝任务。下载中断后再次点击会续传。

语音识别完全在本机运行，不调用 OpenAI 或其他云端识别接口，成片音频不会离开本机。模型只在服务进程内加载一次，后续任务复用内存中的实例。

## 安装

依赖已安装在 `.venv` 中，通常无需重复安装。

需要重建环境时：

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

## 启动

双击 `启动.bat`，浏览器会自动打开。

手动启动：

```bash
source .venv/Scripts/activate
python run.py
```

默认地址：`http://127.0.0.1:8765`。端口被占用时会自动顺延，终端里会打印实际地址。

关闭启动窗口即停止服务。刚替换过程序文件或改过代码时，也要先关闭旧窗口再启动：端口 8765 已被占用时，`启动.bat` 只会打开旧服务，不会重新加载后端代码。

## 使用流程

参数区顶部可以选择两种处理方式：

| 处理方式 | 需要什么 | 字幕文字来自 |
| --- | --- | --- |
| **字幕对齐** | 成片 + 剧本 | 剧本；识别只提供时间 |
| **字幕提取** | 成片 | 本机语音识别结果，按识别段落整段输出 |

选择「字幕提取」后，剧本区和只在字幕对齐时使用的单行字数、补白、无缝衔接、整体提前、句尾延音会变灰不可用，导出位置保持原位；主按钮变成「提取字幕」。两种方式共用模型、导出位置和预览。

### 1. 放入成片

把剪辑好的视频或音频拖入左侧「成片」区域，也可以点击选择。

支持：`mp4` `mov` `mkv` `avi` `flv` `webm` `m4v` `mp3` `wav` `m4a` `aac` `flac` `ogg` `opus`。

放入后，成片区会直接显示时长、画面分辨率和文件大小；纯音频文件会显示「音频」，不显示分辨率。下方预览台会直接播放本地成片；此时还没有字幕。处理完成后，字幕会按时间轴叠在画面上，可边播边核对节奏和断句。右上角按钮可放大到全屏，`Esc` 退出。浏览器无法解码的容器（例如部分 MKV / MOV）会提示无法预览，但文件大小仍会显示，不影响字幕生成。

选错文件时，点击缩略区右上角的 `×` 即可移除；也可以在成片或剧本区域点右键，选择「重新选择」或「移除文件」。移除成片会同时清空预览和本次结果，且不会删除磁盘上的原文件。

页面右上角的外观控制支持「跟随系统 / 浅色 / 深色」；旁边的拉绳也可以向下拉动切换明暗，松手后带回弹。

### 2. 放入剧本（仅字幕对齐）

字幕对齐时，把本集剧本 `.txt` 拖入「剧本」区域。只读取 `角色：台词` 形式的对白行，其他内容自动忽略。

字幕提取不需要剧本，可跳过这一步。提取结果仍然只保留纯台词，并沿用同样的语气词清理和分段规则。

放入后，剧本区会显示预检结果：台词句数、内心独白句数（有独白时）、总字数与文件大小。如果剧本格式不对或没有提取到对白，同一位置会显示原因，并暂时禁用「开始处理」。

素材区底部的「剧本格式」旁边有说明图标，悬停即可查看支持的写法、独白、忽略行和输出规则。

支持中文或英文冒号、`角色1` 这类编号角色名。例如：

```text
角色1:今天，我们来测一下字幕提取
角色2:这段话说的稍微有点快
角色3:你能听清吗
角色4:那个我再讲一遍吧
```

剧本必须与成片是同一集，否则对齐全错。

### 3. 设置参数

默认参数适用于大多数竖屏漫剧。第一次使用保持 `Small + CPU` 即可。

参数里的模型说明图标支持悬停查看：`Small` 最快、`Medium` 更稳、`Large v3` 最准但最慢，可按成片要求选择。

「导出位置」默认留空，文件写入 `data/outputs/`。需要直接导出到剪辑工作目录时，可以输入绝对路径，或点击右侧文件夹按钮选择；目录不存在会自动创建。如果已有同名 `.srt`，会自动使用 `文件名 (2).srt`，不会覆盖旧文件。

浏览器会记住上一次使用的自定义导出位置，点「下一集」重新载入后仍然保留；清空输入框即可恢复默认目录。

### 4. 开始处理

字幕对齐点击「开始处理」，字幕提取点击「提取字幕」。界面会依次显示：

- 字幕对齐：解析剧本 → 识别语音 → 对齐剧本 → 智能分段 → 生成字幕
- 字幕提取：识别语音 → 整理人声段落 → 生成字幕

开始前会检查所选模型是否已在本机。`Small` 已缓存时直接加载；`Medium` / `Large v3` 需要先在参数区的模型状态条点击「下载」，下载完成后按钮才可用。下载时会显示百分比和进度条，同一时间只允许下载一个模型。加载模型只读取本机文件，不会联网；同一模型加载一次后会复用内存实例，后续任务更快。

### 5. 检查结果

处理完成后可以看到：

- **字幕对齐**：对白 / 匹配率 / 待确认 / 噪声 / 字幕；「可疑台词」列出匹配度偏低或没有找到的句子，「噪声」列出被剔除的非台词声音。
- **字幕提取**：人声段 / 字幕 / 时长；每个识别段落对应一条完整字幕，结果区直接显示字幕清单，没有剧本审查项。

两种方式都可以在「字幕」列表点击任意一条，预览台会跳到对应时间。对齐模式通常只需要确认「待确认」里的句子；提取模式检查一遍字幕断句即可导出。

### 6. 预览与导出

处理完成后，预览台会同步显示每条字幕。字幕在切条时会短暂渐入，方便检查是否压到画面重点、是否和口型对上。预览右上角可全屏放大。

处理完成后，预览下方会显示「完成」卡片：SRT 在任务完成时已经写入导出位置，点击「打开文件夹」会直接在资源管理器中定位到该文件；卡片底部显示完整导出路径，可一键复制。「下一集」清空当前任务。

如果完成后又改了导出位置，点「导出 SRT」会把当前字幕文件移到新目录，并同步卡片里的路径，确保两处显示一致。把导出的文件拖进剪映的字幕轨即可替换旧字幕。

如果处理前填了自定义导出位置，SRT 会直接写入该目录；网页上的「打开文件夹」也会定位到实际导出文件。点「下一集」只会清掉任务记录和上传素材，已经生成的 `.srt` 会保留在默认或自定义导出目录里，不会被顺手删除。

导出文件名与成片同名，便于归档。

## 剧本格式

```text
角色：台词
角色（表演提示）：台词
角色（OS）：内心独白
【音效】：不输出
△ 动作描述，不输出
```

识别规则：

| 写法 | 处理 |
| --- | --- |
| `角色：台词` | 作为字幕 |
| `角色（表演提示）：台词` | 作为字幕，括号内容不输出 |
| `角色：台词（表演提示）` | 作为字幕，括号内容不输出 |
| `角色（OS）：台词` | 内心独白，与普通台词一致输出为字幕 |
| `【...】`、`△ ...`、`# ...`、`—...` | 忽略 |
| 场次标题、剧名、集数信息 | 忽略 |
| 空行 | 忽略 |

字幕输出时，剧本中的标点、符号、空格、换行、引号和括号内容全部不保留；这些位置只用于断句和分段。台词中的表演提示（如「（失声）」「【大喊】」）也会在解析时剔除。句尾的「呀、啊、哎、哦、嗯」等语气词会去掉，句首被停顿隔开的「嗯，」「哎，」同样不输出；「吗、呢、吧」保留，避免改变原句语气。

带 `（OS）` 的内心独白也属于需要上字幕的台词，统一输出；界面不提供关闭选项，以免漏掉独白。

剧本编码支持 UTF-8 与 GB18030。

## 参数说明

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 单行字数 | 14 | 仅字幕对齐：单条字幕的最大字数上限；按完整词边界分段，不会刚好到上限就从词中间切开；竖屏漫剧建议 12–16 |
| 模型 | Small | `Small` 最快、CPU 首选；`Medium` 对口音和嘈杂环境更稳；`Large v3` 同音字和多角色最准但最慢。悬停参数旁的说明图标可查看；未下载的模型会在下方显示「下载」状态条 |
| 运行设备 | CPU | 有 NVIDIA 显卡并装好 CUDA 时可选 GPU；GPU 不可用会自动退回 CPU |
| 补白（秒） | 0.6 | 仅字幕对齐：同一句拆出的字幕，间隔小于该值时补满；自然停顿和句末标点不会被补掉 |
| 整体提前（秒） | 0 | 仅字幕对齐：字幕整体提前出现和消失；0 表示严格贴住人声、不改变对齐 |
| 句尾延音（秒） | 0.18 | 仅字幕对齐：每句对白的最后一条字幕延后消失；只影响收尾，不会盖住下一句 |
| 无缝衔接 | 开启 | 仅字幕对齐：同一句台词的多条字幕首尾相接；遇到真实停顿仍保留空隙 |
| 导出位置 | 空 | 留空写入 `data/outputs/`；也可输入路径或点击文件夹按钮选择，会记住上次填写的位置 |

## 输出

默认：

```text
data/outputs/<成片文件名>.srt
```

自定义导出位置时：

```text
<你选择的目录>/<成片文件名>.srt
```

- 编码：UTF-8
- 字幕文字：对齐模式来自剧本，提取模式来自本机识别；只含汉字、字母和数字，不含标点、符号、空格、换行
- 不含表演提示与句尾语气词
- 时间来自音频，字级对齐
- 对齐时默认起始时间严格落在第一个真正发声的字上；可用「整体提前」和「句尾延音」微调
- 提取时严格使用识别段落的时间，不做整体提前和句尾延音
- 字幕提取时每个识别片段完整输出，不按单行字数拆分；对齐时没有对应剧本的识别片段不会写入字幕

参数区的「导出位置」留空时，输入框里会显示默认导出目录；处理完成后，结果区底部的「导出位置」会显示当前字幕文件的绝对路径。上传的素材保存在 `data/uploads/<任务ID>/`，模型保存在 `data/models/`，都可以随时清理。素材不会自动删除；常处理 20 分钟长片时，建议定期清理 `data/uploads/` 里的旧任务目录，避免磁盘越占越多。

## 常见问题

**模型下载失败**

模型不会在后台偷偷下载。需要 `medium` / `large-v3` 时，在参数区选择该模型，再点击下方状态条右侧的「下载」；状态条会显示百分比，中断后再次点击会续传。程序会优先连接 ModelScope 国内源，超时或不可用时自动回退到 `hf-mirror.com`，通常不需要额外开代理。如果两个源都提示超时，再检查网络或代理；`small` 已在本机缓存，断网也能直接使用。

**模型未下载，开始按钮是灰的**

这是预期行为，避免任务跑到一半才失败。先点击状态条里的「下载」，完成后再开始处理。`small` 已缓存时不会出现下载条。

**识别很慢**

先用 `Small + CPU` 试跑；有 NVIDIA 显卡并装好 CUDA 时切到 GPU 会明显更快。20 分钟长片在 CPU 上会等较久，建议先用 `Small + GPU` 实测一集，再决定是否切 `Medium`。识别期间请不要关闭启动窗口。如果系统缺少 `cublas64_12.dll` 等 CUDA 运行库，界面会提示一句，然后自动改用 CPU 重跑，并把运行设备切回 CPU；任务不会直接失败，只是速度会慢一些。

**字幕时间整体偏早或偏晚**

检查「可疑台词」里的匹配率。如果整集都低，通常是剧本与成片不是同一版，或剧本缺句、多句。先让剧本与成片逐句一致，再重新处理。

**个别句子时间不准**

点开对应行试听。若该句在音频里被拆开、重录或删改，对齐会变弱，需要人工在剪映里微调。

**字幕断句不合适**

先调「单行字数」。算法会优先保持完整词和自然停顿，不会从词中间硬切；如果想更碎，可以把「补白」调小或关闭「无缝衔接」。真实停顿处始终会保留间隙。

**导入错了文件**

点击成片或剧本区域右上角的 `×`，或在该区域点右键选择「移除文件」。移除只清理网页里的本次导入和预览，不会动磁盘上的原文件；如果任务正在处理，移除后会停止网页端等待并清空进度。

**自定义导出位置打不开或不可写**

可以直接粘贴绝对路径，例如 `D:\剪辑\第10集`。目录不存在会自动创建；如果系统权限不允许写入，界面会给出提示。非 Windows 系统不支持文件夹选择窗口，请手动输入路径。

**浏览器里不能预览 mkv / mov**

不影响字幕生成。预览只依赖浏览器自身解码能力，SRT 仍会正常写入导出位置。

**端口被占用**

服务会自动尝试 `8765` 之后的端口，以终端打印的地址为准。如果 8765 上还是旧版 SubtitleStudio，`启动.bat` 只会打开旧服务；请先关闭旧窗口或结束旧的 `python.exe`，再重新启动。新版界面遇到这种旧接口会提示「本地服务还是旧版本」，不会只显示「上传失败」。

**上传时提示「本地服务还是旧版本」**

旧的启动窗口还在运行。关闭它（或结束占用 8765 的 `python.exe`），重新运行 `启动.bat`，再刷新网页即可。新接口允许字幕提取不传剧本，旧接口仍要求剧本，所以会返回 422。

**重启后任务还能找回吗**

已完成的任务会落盘到 `data/results/<任务ID>.json`，刷新页面或重启服务后仍可恢复；正在处理时服务被关闭的任务会标记为「已中断」，需要重新开始。已经生成的 SRT 不受影响，仍在默认的 `data/outputs/` 或你设置的自定义导出目录里。

## 技术细节

- 后端：FastAPI + Uvicorn
- 模型：只从本地 `data/models` 加载；未下载时由用户点击后优先从 ModelScope 下载，失败自动回退 `hf-mirror.com`，下载状态由后端线程维护，前端轮询
- 语音识别：faster-whisper，`word_timestamps=True`
- 对齐：全局序列比对（Needleman–Wunsch），同音字按半匹配计分
- 提取：ASR 词级时间戳还原成带时间的人声行；每个识别片段完整输出为一条字幕，只做语气词、标点和括号提示清理，不再按单行字数拆分
- 分段：jieba 词边界 + 标点 / 自然停顿 + 单行字数上限；停顿处保留间隙，完整词不拆开
- 时间：字幕对齐时起点取第一个可见字的字级时间，可按设置整体提前并在句尾轻微延音；提取时严格使用识别段落的时间
- 前端：原生 HTML / CSS / JavaScript，无构建步骤
- 导出：默认任务目录，或自定义绝对路径；同名文件自动编号，不覆盖

## 打包为桌面软件

`run.py` 是打包入口，用 PyInstaller 打成 onedir，详细步骤见 [packaging/README-封装说明.md](packaging/README-封装说明.md)。

- `app/static` 会随包；模型不放进 exe，放在 exe 旁边的 `data/models`。
- 默认**不内置模型**（`packaging/build.bat` 的 `BUNDLED_MODEL` 留空），small / medium / large 都由用户点击下载。
- 想内置：把 `BUNDLED_MODEL` 设为 `small`（或本机已下载的模型名），打包时会从本机 `data/models` 拷入。
- `data/uploads`（上传的成片和剧本）、`data/outputs`（生成的 SRT）、`data/results`（任务记录）**不会**打进安装包，`installer.iss` 只创建空目录。
