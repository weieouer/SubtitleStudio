# 时间状态、路径与帮助速查

版本 2.3.5 · 2026-11-10。

- 时间异常优先显示，人工文字确认仍保留；参考检查不会清掉时间问题。自动完成改为蓝色中性标签，报告与对齐统计不再将异常时长、过期/失败对齐算作成功。
- 默认预览与导出使用编辑区同一份时间；参数仅在“预览微调”时临时生效，常驻提示未应用。“应用到字幕”可撤销，截掉词、缩短却无可靠词时间或存在重叠时整次不应用。
- 原时间也不可信且无法收紧的长条停用词表，保留原记录与明确错误，避免后续继续依赖坏词时间分段。本轮没有重写用户工程或强裁长条。
- “保存工程”与导出分开；项目目录按钮打开真实工程库；导出保留路径和定位/复制操作。
- 帮助改为四步速查、标签和快捷键，移除重复长说明，详细参数使用按钮提示。

验证：[后端 304 项](后端回归.json)、[前端 93 项](前端回归.json)、[浏览器 57 项](浏览器验证.json)通过。浏览器使用隔离目录、合成音频与模拟识别；[帮助布局](帮助布局验证.json)在五种视口均无横纵滚动，包含 1280×720、1024×600 和 390×844。[帮助界面](界面_帮助速查.png) · [状态与路径界面](界面_时间状态与路径.png)。

在线 EXE 2.3.5 实际编译通过，12,222,497 字节；未运行安装向导。首次启动下载依赖的机制未改，前轮真实 HTTP 安装证据继续保留，不冒充本轮安装实测。
