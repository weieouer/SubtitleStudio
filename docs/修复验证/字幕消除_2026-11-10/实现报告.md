# 3.0.0 字幕消除

保留旧版 `main/v2.3.5`，新功能位于 `feature/subtitle-removal`。新增模式不改现有字幕工程；支持独立视频、主题统一选框、全片时间段扫描、手动编辑、撤销、保存、短片原片对比和结果定位。

## 画面保护

- PP-OCRv5 mobile 每帧检测选区内文字，概率图适度外扩覆盖描边和少量阴影；未检测到文字不擦除整框。
- ProPainter 只合成文字遮罩内像素，边缘在遮罩内羽化，明显切镜头分开处理。
- 遮罩外与无字帧在编码前逐像素保持；输出视频仍会重新编码，不承诺完全无损。
- 原分辨率、PTS、像素宽高比保留，完整输出复制原音轨；拒绝 HDR/高位深输入，避免静默损失色彩。

## 已验证

- 后端 322 项、前端 93 项、消除界面 12 项、原有浏览器流程 57 项；帮助五种视口检查通过。详细结果以同目录及上级回归 JSON 为准。
- [真实检测模型](文字扫描实测.json)：合成间歇中文字幕，发现两个时间段。
- [真实 CPU 修复与视频编码](修复模型实测.json)：1 秒、4 帧合成中文字幕，帧数及文字消除检查通过。
- [真实精细遮罩](精细遮罩实测.json)：6 帧渐变背景，白字、黄字黑描边、无字帧；文字及描边覆盖率 100%，遮罩占宽选区约 16%，遮罩外编码前完全相同。[修复对比：原片／结果／干净背景](描边字幕修复对比.png)。
- 界面任务使用接口替身，仅验证交互；不能替代真实模型结果。

## 发布与限制

在线 EXE 安装方式不变，首次启动配置基础依赖；修复环境和约 204 MB 模型按需下载，GPU 推理依赖另计。模型未打包，未改全局 Python。

真实长片、运动复杂背景、渐隐文字、GPU 下载与推理尚未验收。真实素材应先查看 3 秒预览；目前只有 ProPainter 修复模型可用。
