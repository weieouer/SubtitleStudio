# 本机开发环境隔离与便携发布（2026-11-09）

应用版本仍为 2.3.4；本轮调整开发/发布流程，不修改字幕处理或前端产品行为。

## 开发环境

- 基础解释器：本机安装的 Python 3.13.15。
- 主开发环境：`%USERPROFILE%/.virtualenvs/SubtitleStudio`，实际由本机 Python 创建，`include-system-site-packages=false`。
- 日常启动：`py dev.py`；只配置：`py -3.13 dev.py --setup-only`；查看解释器：`py dev.py --print-python`。
- 主依赖使用开发环境自己的 `python -m pip` 安装，支持现有离线 wheels 和联网镜像回退；开发入口启用 `PIP_REQUIRE_VIRTUALENV`、禁用用户包继承并校验主依赖版本。
- Qwen/FireRed 保持独立引擎虚拟环境，模型下载功能保留。旧的项目内 `.venv` 和既有模型未删除。
- VS Code 默认解释器已更新；已记住旧选择的工作区需要重新选择解释器。
- 新增 `.gitignore`，源码上传排除运行环境、发布资源、个人工程/设置、缓存和产物；`runtime` 与 `wheels` 仍在本机供发布使用。

## 全局环境清理

用户要求先完成项目虚拟环境、再清理全局第三方包。本轮按此顺序执行：

1. 创建并安装开发环境，执行后端全量检查及开发/便携首次启动验证。
2. 将全局包清单、精确版本恢复清单、恢复脚本与卸载日志备份到 `%USERPROFILE%/.virtualenvs/_backups/global-python-3.13-20261109-df51a243/`。
3. 卸载 68 个全局第三方包，保留 `pip==26.2.1`、`setuptools==84.0.0`，本机 Python 保留。
4. 清理后重新运行后端全量检查、环境检查、开发 HTTP 启动和便携副本首次启动。项目没有重新往全局环境安装依赖。

备份中的 `restore.ps1` 可按需恢复原全局包，恢复需要可用的安装源。它只作为恢复入口保留，本轮未执行恢复。

## 便携发布规则

沿用 `tools/package_release.py`：保留源码、文档、便携 Python、离线 wheels、引擎配置及当前界面参数；排除开发虚拟环境、项目内虚拟环境、模型、引擎环境、缓存、日志及进程状态。默认不带用户工程与素材。新增 `dev.py` 和 `.gitignore` 随源码保留。

接收方解压后仍双击 `run.bat`，首次启动创建包内 `.venv`，优先离线补齐依赖；进入界面后按需下载模型及配置引擎。ZIP 生成工具会校验必需文件、文件 SHA256、清单一致性和 ZIP CRC。源码开发入口不依赖包内 Python。
