## 行为

- 安装器首次安装、升级均显示目标目录页，保留上次路径并允许更改；选择后及安装前用独立临时目录检查创建、写入和删除权限。支持 `/DIR="路径"`。更换目录不会自动迁移用户数据。
- 字幕和对应参考均存在的文字差异标黄；校准用可靠参考纠正后通过。多识别、没有对应参考、上下文不符或参考正文没有字幕时标红，保留人工判断；校准不自动增删字幕或改时间。
- 缺失正文在右侧以独立行显示，覆盖开头、结尾及完全未对应的正文；不把角色标签和舞台说明当成缺失台词。独立参考行不参与导出。
- “手动补入字幕”“已试听，无需补入”“已试听，保留字幕”均为明确人工操作；补入避开现有字幕占用的时间，操作可撤销，决定随工程保存。人工修改与确认通过，真实音轨时间异常独立保留。
- 重复前一句的定位增加再前一句及后两句的锚点，要求同一来源、连续字幕及局部顺序共同支持。证据不足仍保留待人工判断，不以全文其他位置的命中替代当前场景。
