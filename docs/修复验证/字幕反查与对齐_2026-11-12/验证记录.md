# 字幕反查、空白行与对齐修正

2026-11-12，当前源码工作区，尚未重新构建安装包。

## 最终流程

识别或导入有文字的字幕 → 逐条反向对照剧本校验 → 校准文字 → 人工处理红色项 → 对齐音轨。参考只校验现有字幕，不把未匹配的剧本文字生成空白行。

取消缺句小窗口、独立参考空白行、前后条号提示和补入入口。添加必须先填写文字，取消或空白不创建；手工清空字幕离开编辑时移除空行，可撤销。原有非空识别字幕继续保留。

轻微内容差异为黄色“轻微问题”；无可靠参考、上下文不符、字数/时间等参数违规为红色“明显错误”。各阶段区分“校验通过”“校准通过”“修改通过”“对齐通过”，标签筛选同步，内容通过不掩盖时间或参数问题。

语气词关闭时提取清理，导入和已有字幕只标红；开启时允许保留。旧的幻觉自动排除解除，明确人工不导出保留。原识别评分只说明原模型分数，不能当作文字正确率或对齐准确率。

对齐使用较短上下文窗口；异常词时间或整体明显偏移时尝试局部音频和邻句重试。只有完整文字、词边界、时间顺序和邻句关系均通过检查才采用；仍不可靠时保留输入时间、清空不可靠词表并标红，不继续按它拆句。
