# 两排工具、重新对齐与一键校准实现报告

日期：2026-11-06。应用版本2.1.0。本轮业务改动为前端；未重启生产后台、未更改用户当前工程。保存当前工程后刷新即可启用。

## 已实现

1. 编辑排依次为合并、分段、添加、删除、撤销、重置。处理排依次为关闭导出、重新识别、重新对齐、一键校准；后两项在对齐模式显示。两排按钮均分宽度，最小高度30px、字号12px，全选移到标题行。
2. 移除完成、采用和独立校验小按钮及无人调用的批量函数。重新识别两个模式均可，仍最多10条。重新对齐为全局音轨对齐和参考校验，保留文字；悬浮提示明确全局范围。
3. 一键校准处理选中字幕，未选时处理全部，不限10条。先复用首轮有效参考；缺失/过期参考按必要上下文局部刷新，单请求最多5000条，成功后统一提交目标。可靠错字、谐音、漏字、多字才修正；无参考或不可靠候选保留原文并提示。新结果缺失或刷新失败时不偷偷套用旧参考。
4. 普通疑点显示黄色“疑似问题”，上下文插入台词、对齐错误、异常拖长及确认幻觉显示红色“明显问题”，无问题显示绿色“校验通过”。无参考明确显示“无参考内容”。关闭导出标记独立于校验等级。
5. 修改文字/时间、手动拆分/合并及校准后显示绿色“修改完成”，不叠加旧疑点、待校验或已完成。原ASR和历史参考仍保留。确认快照关联当前文字与起止时间，后续模型改变这些值则旧确认失效；显式全局对齐校验按新结果重新评级，内部校准刷新保留修改确认。
6. 导出仍包含所有未关闭导出的字幕，与勾选范围无关；全选仍包含关闭导出的字幕，便于批量编辑。

## 便携打包

新增`tools/package_release.py`，只读收集源码、文档/验证、便携Python、直接/完整依赖清单、引擎配置和界面参数；排除模型、虚拟环境、缓存、日志、旧进程状态及旧目录记忆。本机模型、依赖和工作文件不变。默认不带工程/素材，可显式加`--include-work`；包内清单记录实际选择与全部文件SHA256。

在含中文和空格的独立临时路径解压后，随包Python3.13.15可运行、创建全新`.venv`并启用pip。验证全程未依赖旧`.venv`内的包，未对原环境安装或卸载。完整pip联网安装、模型下载及真实目标机器GPU兼容性没有在本轮重测，不能将此冒烟描述成全新电脑完整识别验收。证据见`便携包启动验证.json`；最终桌面压缩包另做必需文件/排除目录、全部哈希和ZIP CRC校验。
