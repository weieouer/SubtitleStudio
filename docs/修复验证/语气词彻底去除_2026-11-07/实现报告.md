# 语气词彻底去除与明显问题自动排除（2026-11-07）

对应应用 2.3.2。本轮解决四件事：

- 关闭“语气词”后，整条笑声、叹气、填充音以及句首、句末的“啊、呀、哎、唉、哈哈”等要彻底去掉，不再只是标红或关闭导出。
- 开启“语气词”时保留整条语气词，但校准仍以可靠参考为准，参考中没有的语气词也要删除。
- 校准和对齐后按参考重新校验：参考中不存在的内容显示为红色“明显问题”。
- 明显问题自动变灰、关闭导出；修正通过后恢复绿色和导出。

## 实现内容

### 1. 语气词识别与边界清理

`backend/core/interjections.py` 重写：

- `LAUGH / SIGH / DISDAIN / FILLER` 分别维护笑声、叹气、咂嘴和填充音；`WEAK` 单独维护“啊、呀、哇、哦、噢、喔、哟”。
- `is_interjection()`：整条只由上述字符组成即判为语气词，包括单字“啊？”“哦。”“呀”“嗯？”“哼”“呵”；“喂”等正常对白不算。舞台说明（“笑声”“叹气”等）整条命中才算。
- 新增 `strip_boundary_interjections()`：去掉句首、句末、句末标点旁和标点之间的独立语气词，例如：
  - “啊，我们走吧” → “我们走吧”
  - “我们走吧啊” → “我们走吧”
  - “我们走吧。啊！” → “我们走吧！”（去掉语气词后修正相邻句号/叹号）
  - “走吧，啊，快点” → “走吧，快点”
  - “哈哈，你真会说笑” → “你真会说笑”
  - 保持不动：“你呀，就是太心软了”“走啊，快点”“他说：‘啊！’”“哈哈镜，真有趣”。
- 新增 `strip_interjection_cues()`：关闭开关时删除整条语气词，裁剪其余条目的句首/句末语气词，写入 `edited=True`、`modification_complete=False`，返回删除数和裁剪数。
- `mark_interjections()` 保留给开启状态和校验标记使用；旧 `drop_interjections()` 仍保留给旧接口。

### 2. 提取阶段直接删除

`backend/core/jobs.py` 在分段、修复和设置 `original_text` 之前，对 `asr` / `asr_region` 任务：

- 关闭“语气词”时调用 `strip_interjection_cues()`，删除整条语气词并清理句首/句末语气词。
- 任务 `info` 新增 `interjections_removed`、`interjections_trimmed`，前端完成提示显示删除和裁剪条数。
- 对齐任务仍只处理时间，不删除或改写文字。

### 3. 校准以参考为准

`backend/core/calibration.py`：

- 新增 `_interjection_reference()`：只采纳高度匹配、未过期的错字/谐音/漏字/多字，或已确认歧义；参考标记过期、异位或仅参考条目不算。
- 新增 `_prepare_interjections(items, keep_interjections)`：
  - 关闭开关：整条语气词删除；其他条目用 `strip_boundary_interjections()` 清理句首/句末语气词。
  - 开启开关：整条语气词保留，但可靠参考中不包含该语气词时删除；句末语气词只有在“去掉后与可靠参考逐字一致”时才裁剪，避免误删参考中真实存在的“啊”。
  - `review_decision='included'` 的手动条目完全不动。
- 返回值新增 `interjection_removed`、`interjection_trimmed`；旧的 `interjection_excluded` 固定为 0，供尚未更新的前端读取。
- 删除旧逻辑“关闭开关时给整条语气词写 `exclude_export` 并保留空条目”。

### 4. 明显问题自动变灰、不导出

`frontend/js/app.js`：

- `cueVerificationIssues()`：`extra`、`context_mismatch`、有参考时的 `unmatched` 判为明显问题（红色）；无参考时 `unmatched` 仍为黄色疑似。
- 新增 `applyVerificationExclusions(cues, {indices, requireReference})`：
  - 校准只作用于本次目标条目，对齐作用于全部字幕。
  - 明显问题写 `exclude_export=true` 和 `verification_excluded=true`，表格按现有 `.excluded` 样式变灰，预览和导出同时排除。
  - 后续校验通过时清除 `verification_excluded` 并恢复导出；仍有幻觉、被手动“不导出”或手动“加入导出”的条目不覆盖。
  - 开启“语气词”后仍保留的整条语气词不因红色“语气词”标签被自动排除。
- `calibrateAll()` 在 `rematchDerivedCues(..., {preserveModification:false})` 后调用自动排除，再弹报告；提示追加“N 条明显问题已变灰不导出”和语气词删除/裁剪/恢复数量。
- `alignAndVerify()` 重新校验全部字幕后调用自动排除；排除状态有变化时立即重画表格，再弹报告。
- 手动编辑文字或时间、切换导出、恢复导出会清除对应的自动排除标记。
- 手动合并自动变灰的短碎片时不再继承 `verification_excluded`：只要选中条目里有一条手动“不导出”，合并结果继续不导出；全为自动变灰时合并后恢复导出，避免合并后仍灰着。

### 5. 提示与版本

- `frontend/index.html` 的“语气词”悬浮说明改为：开启保留整条；关闭时提取和校准直接删除，并去掉句首/句末语气词；参考中没有的也去掉；句中“你呀，就是……”不受影响。
