## 实际修改

| 区域 | 处理结果与理由 |
|---|---|
| 时间微调 | 默认折叠为“对齐后时间微调”；摘要显示未设置、已设置参数或预览中。收起只结束临时预览，不改时间和参数，避免隐藏的预览继续影响试听。 |
| 校验入口 | 保留主工具栏“校验字幕”，删除匹配参数内重复调用同一操作的按钮及绑定。 |
| 单条采用参考 | 删除没有生产入口的 `canAdoptCue`、`adoptCue`；参考采用统一走已有的文字校准流程。原指纹、上下文和人工确认测试保留在现行入口。 |
| 剧本匹配 | 删除只供旧测试调用的 `parse_script_text`、`match_script` 兼容包装，测试直接覆盖 `reference_match.match_reference`。DOCX/TXT/MD 读取仍保留。 |
| 旧缺句功能 | 删除空缺参考的前端状态、撤销/草稿/保存传递字段及后端专用校验器。旧记录不会生成空白字幕，旧客户端传来的废弃字段不再写入新工程。 |
| 启动工具 | 删除重复的 `tools/bootstrap_deps.py` 和硬编码旧桌面路径的一次性迁移脚本；同步便携包必需文件清单，实际启动仍使用 `tools/bootstrap.py`。 |
| 旧布局样式 | 删除没有对应元素的旧行内复核操作、开始/结束单元格、旧检查器和旧左侧字幕限制样式。 |
| 重复计算 | 整页刷新通过现有剧本区同步模式与按钮，取消同一轮内的重复调用；没有宣称解决列表整表重建问题。 |
| 命令说明 | 主入口帮助由“构建便携包”改成实际默认行为“构建完整安装包”。 |

## 明确保留

用户选择保留的主题、拉绳、操作音效和 MKV 导出不变。旧便携启动、打包和校验链仍有用途，保留 `bootstrap.py`、`package_release.py`、`build_portable`、便携 BAT 模板、运行库和 wheels。

旧安装包、安装暂存、模型、引擎、缓存、素材及工程不属于本轮无用源码清理范围，没有删除。
