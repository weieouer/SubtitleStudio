# UI 与字幕流程更新验证

更新日期：2026-11-04。

统一字体与数字字体族，提亮深色灰蓝配色；增加本地 CSS 淡入、悬浮抬升和按钮切换反馈，遵循系统减少动态效果偏好。样式参考 [Animate.css](https://animate.style/) 的经典淡入模式，没有新增联网运行依赖。

复选框固定为 15×15，不再套用工具栏文本输入框的高度与焦点阴影；说明提示延迟悬浮显示，点击后隐藏。导出设置独立成面板，包含保留标点、补句末标点、排除疑似噪音字幕、跳过空字幕、单行输出、角色名和数字格式。标点处理保留数字及英文词内的连接符，所有导出处理均使用副本。

提取任务生成原始 SRT，文件名和来源显示在两个素材框下方。切换对齐时沿用当前字幕及已校对的文本、时间和置信度；直接对齐需手动导入 SRT。对齐不重新发起语音识别。文件来源随工程保存，并支持替换字幕后的撤销、重做。先导入独立 SRT 再选择新媒体时，字幕仍被保留。

检查结果：34 项后端回归、20 项浏览器检查通过。浏览器使用临时媒体与模拟识别引擎验证界面、任务交接、真实 SRT 文件解析、工程持久化、导出、声波校时、撤销及无未捕获异常；不代表重新评测模型识别准确率。测试配置与工程保存在系统临时目录。
