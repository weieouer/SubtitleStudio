# 上下文校验、独立分段、标点及分段标签

2026-11-06。本轮四项一起完成并启用。后端202、前端59、隔离浏览器50项全过。生产后台已在确认最近ASR/对齐任务done、下载idle后按普通方式重启；运行接口验证上下文异常和中间独立拆分通过。未代为保存、刷新页面，未修改用户工程或素材。

## 1. 当前片段没有的台词标红

全文找到同句不再足以让夹在可靠前后文中间的字幕通过。用至少4字、全文唯一的前后台词作为位置锚点；同来源且顺序合理、局部跨度有界时，中间1–3条字幕必须在这段局部文字中对应。没有可靠局部对应的条目在DP阶段禁止用别处命中或组合匹配把它吞入。

结果为context_mismatch / 红色“疑似多余台词”，字幕文字也标红，参考框提示“当前片段无此台词”。展开可查看前后定位提醒及全文其他候选；其他候选标为reference_only，不可通过采用/校准直接写入。字幕、起止时间和原ASR保留，不自动删除或改“不导出”状态。

原有多剧本乱序、文件间切换及返回能力保留；连续或反复的其他来源存在独立有序台词证据时，不把正常场景切换一概判成插入。单独校验或新分段局部重匹配会携带目标前后各3条邻文及sequence_indices，只更新目标。跨不连续选择的缺口不得伪装成相邻对白。

实现：reference_match._context_constraints / _context_candidate / match_reference；app._match_script验证顺序号；前端rematchDerivedCues及校验提醒。

边界：纯文本只能提示疑似，不能代替试听。重复/过短/错字过多的锚点、不明确的剪辑及大跨度跳转不作强局部断言。当前采用最多3条夹入、前后20秒、至多120个标准化字符的有界局部证据；检索唯一锚点使用稀有二元组，候选过密时放弃该锚点。不是任意语义理解或所有识别错误都已捕获的保证。

## 2. 长句在中间附近独立拆开

原分段按钮是复制全文为两条，要求手动删减；现改为调用mode=midpoint，真正按中间附近的完整词边界拆开文本。长句超出两条容量时按全局字数上限生成更多独立子条。完整词本身没超限时不从词内硬切。

宽度分段DP加强长度平衡，停顿和标点辅助选择。可用词时间直接继承；词间空档保留，无可靠词时间时按文字范围估计并提示。各子条拼起来严格等于原句，时间不越出父条；前后原字幕不被拼接、覆盖或借用时间。

手动拆分以及不同split_parent之间禁止碎片自动合并。保留原ASR和可靠参考区间；没有可靠参考的子条只重新校验自身，邻文仅提供定位，不改邻条。

实现：segment.split_text / segment_cue / segment_midpoint / repair_fragments；app._segment；前端doSegment。

## 3. 标点开关统一显示和导出

关闭：字幕编辑框、参考、候选、预览、时间轴和实际导出都去标点。开启：显示和导出已有标点。数字内部小数点、时间分隔及百分号等继续按既有数字规则保留。

开关不改底层文字及原ASR，关闭再开启可恢复。关闭时编辑，按可见文字的改动范围替换底层文本，未改动前后部分的隐藏标点保留；整句重写不凭空生成新标点。没有实际文字变化的输入不会清空词时间或把隐藏标点删掉。

实现：editableCueText / mergeEditedCueText、renderTable及编辑事件；导出继续使用subtitleText/现有后端格式化。

## 4. “已分段”标签只用于真正的长句拆分

新增明确width_split来源标记：只有父条文字超过当时字数上限、实际按宽度拆分的子条显示“已分段”。普通停顿断句、未超限短句的手动拆分不显示。旧工程仅从明确dynamic_programming_word_pause宽度来源推断，不再把所有gap_split都贴标签。合并后清理旧拆分元数据。

这项调整标签含义，不自动合并当前字幕，也不改变停顿阈值的实际断句规则。
