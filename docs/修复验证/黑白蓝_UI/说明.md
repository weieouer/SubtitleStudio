# 黑白蓝 UI 更新

2026-11-04 最终配色：浅色为白灰背景、深色文字；深色为黑灰背景、浅色文字。两种主题统一蓝色按钮，带轻微反光渐变、边缘高光、凸起阴影和按压反馈。自动跟随系统只在这两种主题间切换。

素材 SRT 和导出说明收进问号，悬浮或键盘聚焦时查看。文件栏保留文件名、字幕条数等状态信息。“每行宽度”更名为“每行字数”，计算方式和范围保持原设置。

导出选项收敛为“标点符号”“排除疑似噪音字幕”“跳过空字幕”“每条输出为单行”“使用阿拉伯数字”。标点开关只控制保留或去除，不补句末标点，不加角色名；旧工程中的补标点和角色名配置不会重新启用这些操作。

素材区“加入队列”直接加入当前视频或音频并滚动到左侧最下面的批量队列。未选择素材时打开文件选择；队列内“添加文件”支持多选。列表显示文件名与任务状态，防止重复加入，支持移除和清空。

21 项浏览器检查通过，包括当前素材加入队列、列表可见、防重复加入、清空，以及现有字幕提取到对齐的文件传递、导出和时间编辑流程。识别引擎使用模拟实现，文件解析、工程保存与导出调用真实后端，配置与媒体位于临时目录。
