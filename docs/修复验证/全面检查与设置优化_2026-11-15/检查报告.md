# 全面检查与中文短剧设置优化

本轮按“中文短剧／影视对白”检查。语气词按用户开关执行：提取时关闭直接去掉，开启保留；推荐参数不会替用户改变开关。用户选择本轮不下载GPU运行环境。

## 已检查的范围

| 范围 | 检查方法与结论 |
| --- | --- |
| 识别与音频 | 核对Whisper、Qwen、FireRed调用、设备选择、VAD、分块与词时间；两个已安装的Python环境通过pip check |
| 参考与校准 | 逐句候选、字簇位置、中文数字、歧义/上下文、手动参考、拆分合并和不改原始识别记录 |
| 对齐与分段 | 核对成功/失败处理、局部重试、词表失效、邻句边界、全部失败提示及人工参考句界 |
| 编辑与恢复 | 双侧编辑、撤销、保存、跨页冲突、断网草稿、失联工程和重新关联；浏览器验收通过 |
| 导出与文件 | SRT/MKV、毫秒时间、原音轨、范围/重叠校验、独立导出路径；既有完整回归覆盖 |
| 模型与安装 | 固定版本、损坏就绪记录、配置类型、环境状态、安装器/启动器回归；本轮未重新构建EXE或重装环境 |

源码静态检查覆盖74份项目Python文件、6份前端业务脚本，排除运行环境、构建暂存和第三方依赖。静态语法检查及回归通过不等于每个分支、所有硬件和所有真实素材均已验收。

## 本轮修复与优化

1. 中文数字只在连续原文范围内换算，不跨逗号、空格或换行合成新数字；参考句界不会落进同一原数字字簇。
2. 编辑显示文本时保留未改动部分的隐藏标点，新输入的标点也保留在工作记录中，避免再次编辑丢失参考句界。
3. 人工参考跟随拆分、合并，避免重复整段、只保留第一段或在数字换算边界抛错；差异过大时提示复核。
4. 已采用且文字一致的人工参考参与断句；标点显示关闭时也使用原参考句界。无关的人工参考不强行拆当前字幕。
5. 同一条字幕的参考映射及句界只建立一次，全部词边界共用，减少逐词重复标准化和编辑距离映射。
6. Qwen/FireRed长段输入优先寻找块尾附近可靠的低能量区，保持完整样本覆盖及25秒上限；没有可靠低谷时维持容量切点。1419.5秒真实媒体规划成58块，耗时约0.012秒，无丢样本；声学检查不能证明识别准确率提高。
7. 新增“推荐参数”，用于中文短剧校对；保存到设置和工程，任务运行中禁用，不改字幕或模型。
8. 人工参考字段增加后端类型校验；损坏或错引擎的就绪标记不再报告可用；引擎配置类型错误安全回退。
9. FireRed在线准备使用config/firered.json中的固定提交，与完整包保持一致；固定版本文件按内容使缓存失效，覆盖Windows快速写入时间戳未更新的情况。
10. “高度匹配”参数更名“高分门槛”并解释用途；完全一致才显示高度匹配，谐音、错字和漏字仍提示复核。设备提示不再承诺所有引擎运行错误都能自动回退。

## 推荐怎么设置

重启源码程序后，点击左侧“参数”旁的“推荐参数”。这个操作不会重跑字幕或安装GPU环境。

| 设置 | 中文短剧建议 | 原因 |
| --- | --- | --- |
| 设备 | 自动 | 目前本机实际使用CPU；安装GPU环境后再检测可用性 |
| VAD | 开启 | 减少静音区进入识别；仍需复查音乐、轻声和重叠对白 |
| 语气词 | 按开关 | 用户确认：关闭提取直接去掉，开启保留 |
| 停顿 | 0.6秒起步 | 连贯对白减少碎片；参考明确句界仍会拆开，不受此阈值影响 |
| 每行字数 | 20 | 作为默认起点，根据画面和阅读密度调整 |
| 标点 | 开启 | 只显示问号、感叹号、省略号；参考原句读仍参与匹配和断句 |
| 换行 | 开启 | 显示与导出沿用统一宽度规则 |
| 时间微调 | 全部0 | 先靠音轨对齐；有需要再显式预览和应用 |
| 匹配参数 | 最低0.64、高分0.94、拼音0.90、候选分差0.035、相邻3条 | 保持现有保守默认，不用降低门槛制造更多通过项 |
| 主模型 | 保留当前可用模型 | 本轮没有用人工标注样本证明某个模型更适合此片，推荐参数不擅自换模型 |

已检测到RTX 4060，显存8188 MiB；当前Whisper实际选择cpu/int8，Qwen环境为torch 2.15.0+cpu，CUDA不可用。是否安装GPU环境取决于用户，本轮按要求暂不下载。切换“自动”本身不会安装GPU依赖。

## 仍需要继续验收的地方

- 上轮真实强制对齐抽测10条，7条成功、3条仍需试听；本轮没有重新标注全片或测算错漏字率，不能宣称所有字幕均能自动准确对齐。
- GPU安装及真实GPU推理按用户选择暂不执行；中文主模型之间的质量差异需要同一组人工标注片段比较。
- 5000条仍整表渲染，建议下一轮评估局部行更新/虚拟列表；只重对齐选中字幕尚无界面入口。
- 历史缓存/拖入副本清理、Big5编码选择、多语言强制对齐、任意依赖变化的完整环境指纹仍列入待办。
- 本轮修改在源码中；当前运行页面需保存工程后重启才能加载全部前后端变化。安装版未重新打包。

## 参考的官方资料

- [faster-whisper官方说明](https://github.com/SYSTRAN/faster-whisper#vad-filter)：VAD默认过滤较长静音，并支持自定义；开启VAD不是人声分离，也不能替代试听。
- [Qwen3-ASR官方说明](https://github.com/QwenLM/Qwen3-ASR)：强制对齐依赖文字与音频配对，支持词/字时间；本项目保持较短的本地窗口及失败复核。
- [FireRedASR2S官方说明](https://github.com/FireRedTeam/FireRedASR2S)：AED提供时间戳参数；本项目继续请求模型时间，未把估算时间包装为真实词时间。
