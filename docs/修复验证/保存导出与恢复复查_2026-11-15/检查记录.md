# 保存、导出与恢复复查

本轮重新执行后端、前端、隔离浏览器及草稿恢复回归，重点检查导出后重新读取、时间精度、旧工程保存与参考文件位置。测试使用临时工程和合成媒体，没有批量修改用户现有工程、下载GPU环境或重新构建安装版。

## 复现与修复

| 问题 | 修复后行为 |
| --- | --- |
| 字幕内部含空白段落，导出SRT后重新导入只剩空白前的文字 | 仅在SRT输出中去掉空白段落，保留所有非空文字行；工程原文保持不变 |
| 1毫秒重叠被容差放过，部分亚毫秒时间四舍五入后变成零时长 | 导出前按实际毫秒精度检查并提示；内部格式化也保证正时长，不静默修改用户工程时间 |
| 初始字幕的可修复词时间倒序，使已经校正的当前字幕无法保存 | 与当前字幕采用相同词时间修复规则：清除不可用词表并标记异常，保留初始文字和原始识别记录；NaN等非法输入仍拒绝 |
| 清除素材、恢复独立SRT工程或载入跨页冲突版本后，参考文件路径可能沿用上一工程 | 清除时重置路径；恢复时读取对应工程自己的路径 |

新增后端边界用例[初次执行](新增后端初次复现.json)有4项失败、1项错误，修复后6项全部通过；新增前端场景初次有2项失败，见[初次前端复现](前端初次复现.json)。实际浏览器新增验证了SRT空白行后的文字保留、1毫秒重叠和零时长拦截；跨页恢复新增验证了参考路径恢复。
