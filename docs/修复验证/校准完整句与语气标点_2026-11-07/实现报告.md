# 校准完整句与语气标点

日期：2026-11-07。按用户最后确认，开启字幕标点只显示问号、感叹号，不显示逗号、句号；关闭则连问叹号也隐藏。

## 实现结果

- 校准末尾增加句子整理。“中 / 毒的人”有完整词跨界证据时合为“中毒的人”，时间合为两条的完整跨度，保留每条原ASR来源。单字在两条之间时优先选择能组成完整词或有同句参考证据的一侧，不直接补到下一条。
- 合回必须满足全局字数上限、用户停顿阈值、短间隔及可信同句/同源/词语证据；独立答话、明确句末、手动分段、不同导出状态或未选邻条不吞并。仅所选连续区间内整理，不影响未选字幕。
- 先按原文/可靠剧本的明确句界把两句话分成独立字幕，再隐藏逗号、句号等普通标点，最后按全局停顿与宽度处理。隐藏标点不再造成多余超宽拆条，不把后半句拼入原本下一条字幕。
- 有可靠词时间时，以句末标点两侧的真实词首尾分句，保留中间静音及显示封顶；没有词时间或文字无法映射时，分句时间明确标为估计，仍在原条范围内。
- 字幕、参考/候选、预览、时间轴和SRT/MKV导出统一只保留问叹语气标点。数字小数点、千分符、12:30、百分号和英文词内部连接符保留。关闭标点时问叹号隐藏，切换不改原ASR。
- 同字但缺标点的字幕也可使用可靠、高度匹配的剧本补回语气标点；不以过期、歧义或异位参考猜语气。原文没有可靠句界/语气证据时不宣称能够仅凭规则理解所有句子。
- 无参考、上下文明显问题不因去掉普通标点自动变成绿色“修改完成”。有参考的实际校准/结构修改保留绿色确认及整批一次撤销。

本轮新增后端逻辑，已在隔离后台验证。用户正在运行的正式后台未强制重启，以保留当前页面和任务。保存工程、结束任务后需重启后台并重新打开页面，仅刷新页面不能启用新接口；重新执行校准才会整理已有字幕。
