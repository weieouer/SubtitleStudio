# 字幕边界 VAD 二次校验实现报告

日期：2026-11-07。应用版本 2.1.0。本轮只修改后端对齐边界计算与测试，不改变界面布局、参数默认值和导出格式。已在主环境全量回归；真机对齐验证在独立临时目录用 Qwen3-ForcedAligner 执行，未改动用户工程。

## 问题

识别或强制对齐给出的一条字幕，若说话前有音乐、噪声、单音或撞击声，起止时间常被拉成整段“声音”，字幕明显早于开口；句尾音效同理会让字幕拖到说话结束之后。

原因有三处：

1. `speech_intervals` 只看 RMS 和频谱变化。音乐、噪声、音效与随后的人声在能量上连成一段，阈值分不开。
2. `refine_boundaries` 的常规微调上限是每端 180 ms，开头的音乐往往超过这个距离。
3. 有词时间时，`candidate_start = min(candidate_start, words[0].start)` 会把起点拉回首词之前，RMS 的收紧被抵消。

因此需要一种“是不是人声”的独立判断，而不能继续调 RMS 阈值。

## 方案

在 `backend/core/audio_boundaries.py` 中复用 faster-whisper 1.2.1 自带的 Silero VAD ONNX 模型（`faster_whisper.vad.get_vad_model()`，随依赖安装，不额外下载），对每条字幕做一次整段人声判定，只用于**收紧**首尾边界。

| 环节 | 做法 |
|---|---|
| 推理范围 | 每条字幕 `[start−0.3, end+0.3]` 一次推理；整段上下文比分两次截窗口稳定 |
| 帧与阈值 | 512 采样 / 32 ms 一帧；进入 0.5、退出 0.35 的双阈值，连续 4 帧（128 ms）才算语音，连续 4 帧静音才结束 |
| 起点 | 取与首词重叠最多的语音区间；语音起点须晚于原起点 120 ms 以上、跨度不超过 3 s，并在首词结束前保留至少 50 ms |
| 终点 | 取与末词重叠最多的语音区间；语音终点须早于原终点 120 ms 以上、跨度不超过 3 s，并在末词开始后保留至少 50 ms |
| 尾端上限 | 终点候选不超过 `末词结束 + 0.15 s`，避免 VAD 把句尾音效继续吞进来 |
| 轻声保护 | 待裁区域若出现持续 ≥96 ms 或占比 >15% 的 0.30 以上概率，视为可能是轻声人声，放弃该次裁剪 |
| 只收紧 | VAD 结果不会把边界向外扩张；无词时间、模型缺失、结果不确定或会删掉整词时保留原时间 |
| 记录 | `audio_refinement.vad_trim` 写入建议值与是否采用（`start` / `end` / `applied_start` / `applied_end`） |

任一 VAD 调用异常都会把 `_VAD_DISABLED` 置为真并静默退回原有 RMS 方案，不影响识别和对齐任务本身。

## 实测

样本用真实语音（项目内素材与 Windows 中文 TTS“今天天气不错我们一起去公园散步吧”）拼接音乐、白噪声、单音和撞击声。误差 = 输出边界 − 语音真值。

| 场景 | 真值（秒） | 处理前（秒） | 处理后（秒） | 误差 |
|---|---|---|---|---|
| 音乐前缀 + 真人语音 + 单音尾 | 0.800–2.784 | 0.000–3.484 | 0.812–2.804 | +12 ms / +20 ms |
| 前缀矩阵：音乐 / 噪声 / 单音 / 撞击声，各接 1.6 s 真人语音 | 起点 0.800 | 0.000 | VAD 起点 | −20 ms |
| 尾部矩阵：2 s 与 4 s 语音后接音乐 / 单音 / 静音 | 终点即语音尾 | 拖到音效结束 | VAD 终点 | +20 ms |
| 尾部撞击声 | 同上 | 同上 | 同上 | +84 ms |
| 尾部宽带噪声（2 s 语音） | 同上 | 同上 | 同上 | +244 ms |
| 尾部宽带噪声（4 s 语音） | 同上 | 同上 | 未裁剪 | 保持原时间 |
| Qwen3-ForcedAligner + TTS + 音乐前缀 / 单音尾 | 0.800–4.712 | 0.000–5.512（人为拖长） | 0.780–4.790 | −20 ms / +78 ms |

真机对齐一例中，对齐器给出的词时间为 0.800–4.640，本身已准确；把整条字幕人为拖成 0–5.512 后，VAD 二次校验把首尾收回 0.780–4.790，说明词时间正确时 VAD 不会破坏结果，词时间被拉长时能补回。

轻声说话前缀、宽带噪声尾部和音调式持续音是已知弱项：前者按“疑似轻声”保护、不裁；后者可能多留 0.1–0.8 s。所有裁剪都以词时间为锚点，VAD 不会单独把边界推到没有词的区域。

## 测试

新增 `tests/test_boundary_vad.py`，14 项：

- 区间压缩：短爆音被忽略、短凹陷被桥接、孤立尖峰不算轻声。
- 起点：音乐后的语音起点、拒绝抹掉首词、轻声前缀保护、后续可疑区间不取消已找到的起点。
- 终点：噪声前的语音终点、语音贴着边界时拒绝裁剪、末词后 150 ms 上限、更早的可疑区间不影响尾部判断。
- 集成：VAD 越过 180 ms 上限收紧并同步裁剪词时间、VAD 不可用时保持原边界、终点早于末词起点时拒绝。

全量结果：后端 **225 项通过**（原 211 + 14），0 失败、0 错误；浏览器联调 **53 项通过**。前端函数回归 65 项为本机 Node 缺失下的最近记录（2026-11-06），本轮未重跑。

性能：3.2 s 样本每条字幕约 5.6 ms（20 次均值），模型首次加载约 138 ms，对识别和强制对齐耗时可以忽略。模型随 faster-whisper 提供，不增加下载。

## 复现

项目根目录：

```bat
.venv\Scripts\python.exe -m unittest tests.test_boundary_vad -v
.venv\Scripts\python.exe tests\run_backend_checks.py
```

构造样本需要真实语音和 PyAV 解码；单测直接注入确定性的 VAD 概率曲线，不依赖模型文件，因此在没有下载模型的机器上也能运行。

## 已知边界

- 只处理带词时间的字幕；没有 `words` 的条目保持原边界。
- 单端最远收紧 3 s；超过该距离的音效前缀不会被完全裁掉。
- 持续宽带噪声、音调式持续音、多人重叠仍可能多留 0.1–0.8 s，需要人工试听。
- 首尾词本身被模型异常拉伸时，最多只能收紧到词内保留 50 ms，不会为了对齐而删掉整个词。
- 未做全片真实对白的端到端准确率评测；真机验证仅为一条 TTS + 强制对齐快照。
