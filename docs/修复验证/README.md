## 目录与命名

- 轮次目录：`<主题>_<YYYY-MM-DD>/`。主题简短、不加空格，日期放末尾。
- 报告：统一命名 `实现报告.md`。早期的 `说明.md`、`README.md` 保留原名，不再改名。
- 证据：后端 `后端回归.json`、`后端回归日志.txt`；前端 `前端回归.json`；浏览器 `浏览器验证.json`；截图 `界面_*.png`。
- 截图只保留并引用每轮的最终项目界面，不在文档里展示修改过程图。根目录的 `工具栏_一行/两行/缩短后`、`波形_正常波浪/矩形图`、`幻觉徽标` 是早期过程图，不作为验收证据。
- “结果”只写该轮实际运行并留存证据的数字；只更新用例、没有复跑时必须注明“已更新未复跑”。
- 根目录下的同名 JSON 和截图是跨轮汇总或早期产物，可能被后续轮次覆盖，不作为某一轮的单独证据。
- 无日期的 `黑白蓝_UI/`、`全文参考校验/` 是早期记录，只读保留。

## 复现

```bat
.venv\Scripts\python.exe tests\run_backend_checks.py
node --input-type=module -e "import fs from 'node:fs/promises'; import {runFrontendTests} from './tests/frontend_regressions.mjs'; const r=await runFrontendTests(await fs.readFile('frontend/js/app.js','utf8')); console.log(JSON.stringify({total:r.results.length,all_passed:r.all_passed})); if(!r.all_passed) process.exit(1)"
.venv\Scripts\python.exe tests\serve_fixture.py
.venv\Scripts\python.exe tests\browser_smoke.py --url http://127.0.0.1:<fixture端口>
```
