浏览器使用独立临时配置与临时素材，没有操作日常浏览器或实际工程。文本匹配、导出与保存由真实后端处理；模型下载传输及 ASR/强制对齐推理在浏览器测试中使用模拟实现。因此这些结果证明流程与接口连接正常，不代表五个实际模型均已在本机下载或推理通过。
