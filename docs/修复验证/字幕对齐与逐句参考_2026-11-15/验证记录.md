# 字幕对齐、逐句参考与双侧编辑

按本轮确认的要求：参考使用全部标点断句，显示标点开启时仅保留问号、感叹号、省略号；小数、时间、百分号和英文词内部符号保留。

修改内容：

- 参考候选加入句界约束和完整句候选，避免模糊窗口串入相邻半句；接近整句时优先完整参考，句尾漏字不再因截短片段而判为高度匹配。多条字幕仍可顺序引用同一句的不同部分。
- 参考中的逗号、冒号、省略号等参与对齐后拆句，标点显示开关不影响句界判断。
- 左侧当前字幕和右侧参考均可编辑；无参考时允许补写。人工参考独立保存，点击“采用此句”才改当前字幕。保留原始识别和原文定位记录，支持保存、撤销。
- 对齐失败项按当前句的时间范围重试，失败条目的异常旧范围不再拖坏相邻成功句；返回成功/失败数量，全部失败时不播放成功音、不显示成功提示。

浏览器新增覆盖：无参考补写、采用到当前字幕、保存工程、逐步撤销和原始识别保持完整。后端新增覆盖：句尾漏字、全部句读断句、数字内部符号不拆句，以及失败长范围不清除相邻成功时间。

真实模型仍无法可靠定位“有料”“这是给你们的”“多了一块巨石吗”三句：前两句含无效词时间，后一条词时间跨越过长空档。保留这些条目的输入时间并标记待试听复核；本次抽测不能视为全片字幕正确率验证。未自动修改用户已有工程，未重新打包安装版；运行中的程序需要重启加载后台修改。
