## 三模式统一、校准契约与完整运行库（2026-11-11，3.1.0）

三种模式统一为左侧素材与参数、中间浏览、右侧操作；任务进度固定在中间栏底部随布局占位，不再悬浮遮挡状态栏，三个模式等高。设备环境说明进入同一个设备外框并跟在选中项后面，字幕素材框恢复紧凑高度，字幕消除素材卡与另外两个模式的素材卡等高。右侧按钮按“提取字幕、重新识别”与“校准字幕、对齐字幕”分组，提取和重新识别只改左侧工作字幕；字幕消除的预览与开始按钮同样放在面板顶部。

校准改为只复制已确认的参考文字，不新增、删除、合并、拆分或改时间，删行不恢复；标点开关保留原文或统一去除，原始参考与 ASR 记录不动。对齐负责位置、起止和长度，参考句界与音频停顿参与分段。提前、延后、最短、最长显示默认全部为 0。三项素材齐全后才询问是否对比校验。

字幕消除区分模型权重下载与依赖安装，下载支持续传、校验和重试，CPU 改走 PyTorch 官方源；完整安装包在构建期由 `tools/prepare_runtime.py` 准备 Qwen/FireRed/ProPainter 共用运行库，安装后不运行 pip，仅模型按需下载。

真实视频底部字幕条曾让消除任务整体崩溃：细长选区使 RAFT 相关金字塔末级只剩 1 像素，采样除以 0 得到全 NaN 光流，NaN 偏移进入 `deform_conv2d` 触发访问冲突。现在处理尺寸每条边不低于 128，优先在原片内扩边、画面不足时再放大，并在光流出现非有限值时显式报错。原崩溃的 640×268 场景 4 秒预览 96 帧完成。

后端 320、前端 92、隔离浏览器 57、消除界面 12 项通过；真实 ProPainter CPU 合成短片与真实视频预览通过。完整安装包（372.1 MB）已构建，用暂存目录内置运行库启动时全部引擎运行时 ready、无 pip 子进程；干净机安装向导与卸载待验收。真实长片、复杂背景与 GPU 链路仍未验收。详见 [需求与验收](3.1.0需求与验收.md)。

## 字幕消除与画面保护（2026-11-10，3.0.0）

保留 `main/v2.3.5`，在 `feature/subtitle-removal` 加入独立消除模式。统一选框样式，支持全片文字时间段检测、手动编辑和短片对比。修复改为逐帧文字遮罩并覆盖描边，不再擦除整个矩形；明显切镜头分段，无字帧和遮罩外像素在编码前保留。输出另存、原音轨复制、原 PTS 与像素宽高比保留，拒绝 HDR/高位深降色。

真实 CPU 模型通过合成白字、黄字黑描边与无字帧验证；真实长片、复杂背景与 GPU 链路仍未验收。在线 EXE 打包规则保持不变，环境和模型按需下载。详见 [实现报告](修复验证/字幕消除_2026-11-10/实现报告.md)。

## 时间状态、路径与帮助速查（2026-11-10，2.3.5）

文字确认不再遮住时间错误；问题标记、复核筛选、报告与对齐统计统一。预览默认与导出共用编辑区时间，微调需显式预览/应用，应用可撤销，可能裁掉发声时不应用。无法定位的异常长条停用不可靠词表，保留原始记录。工程保存与导出路径入口明确，帮助压成一屏速查；五种视口实测无滚动。

## 设计检查与在线 EXE 验证（2026-11-10）

默认发布改为在线 EXE，首次启动创建隔离环境并联网安装依赖，模型仍由界面按需下载。实际编译 2.3.4 安装包 12,222,511 字节；后端 303 项通过。无包内 wheels 的隔离副本通过本地 HTTP 下载并安装 27 个依赖，服务与模型接口就绪，全局包列表未改变；未验证安装向导交互、公网镜像速度或真实识别效果。证据见 [首次启动验证](修复验证/在线EXE首次启动验证.json)。安装器源码保留，旧 ZIP 工具不再作为默认入口。

检查已有工程发现 8 条超过时长警戒值，最长 4 字持续 82.880 秒；原时间也异常。形成 [设计检查与改进建议](设计检查与改进建议.md)，优先处理对齐失败、确认标签遮挡时间问题、预览与导出时间不一致；本轮只读分析与记录，未修改业务算法或已有工程。
