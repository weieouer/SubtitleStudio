# 3.1.0 用户要求与验收

记录日期：2026-11-11。基线为 v3.0.0（提交 87fbd0a）。下列要求均来自本轮对话；未通过验证的项目不能标为完成。

## 发布与运行

- [x] 修复字幕消除的模型下载、环境配置问题，区分模型权重下载和依赖安装，失败可重试。
- [x] 默认安装包内置基础及所有可选引擎的运行依赖，安装后打开直接进入程序，用户只需选择下载模型，不在用户电脑在线安装依赖。完整版安装包已构建，并用安装暂存目录的内置运行库直接启动验证；干净机安装向导与卸载仍未实测。
- [x] 保留开发虚拟环境隔离，不修改全局 Python；版本号已更新为 3.1.0。提交与版本标签在本轮收尾执行。
- [x] 三个模式的下拉框统一为同一套主题、尺寸、键盘和菜单交互。

## 布局、素材与操作

- [x] 三种模式统一为左侧素材与参数、中间浏览、右侧操作。
- [x] 移除“关闭导出/开启导出”操作，用户通过删除处理不需要的字幕。
- [x] 右侧“提取字幕”放到“重新识别”左边，替换旧“关闭导出”按钮；后续保留“校准字幕”“对齐字幕”两个按钮。
- [x] 提取及重新识别只更新左侧工作字幕，不自动覆盖右侧对比参考，不偷偷启动对比校验。
- [x] 素材区域为空时点击选择文件；已有素材时点击定位该素材所在文件夹。保留清除、拖入及重新选择的明确路径。
- [x] 音视频、SRT 和参考文本三项齐全后，只弹窗询问是否开始对比校验；不自动改字幕。此项已由用户明确确认。
- [x] 设备框内的环境说明与“自动/CPU/GPU”选择共用同一个外框，不再嵌套第二层输入框；说明文字跟在当前选中项后面同一行（如“自动 CPU 环境 · 约 2.9 GB”）。
- [x] 字幕素材框恢复原有紧凑高度；字幕消除的素材卡与另外两个模式的素材卡等高（264 px），切换模式时左侧栏不跳动。
- [x] 中间栏底部任务条在三个模式保持相同高度（56 px）。
- [x] 字幕消除右侧“预览当前 3 秒 / 开始消除 / 取消处理”移到面板顶部，与另外两个模式的操作按钮位置一致。

## 对比校验、校准、对齐

- [x] 第一阶段名称固定为“对比校验”。按字幕条及前后上下文定位参考，检查错别字、谐音、漏字/多字、漏句/多句、上下文不符，标出问题。
- [x] 参考里有整句话但字幕缺少对应条目，只标红为疑似漏句，待用户判断是否实际说了；不自动插入。此项已由用户明确确认。
- [x] 校准以对比定位且可确认的右侧参考为主，只把右侧文字填入左侧字幕；不恢复已删除内容、不新增或删除字幕、不合并或拆分、不改时间。
- [x] 标点开启时保留参考原文标点；关闭时按统一规则去除。阿拉伯数字转换、显示换行在字幕编辑、参考、预览及导出一致，原始参考和 ASR 记录保留。
- [x] 校准后弹出报告，由用户继续执行对齐，不能自动串联造成额外改动。
- [x] 对齐负责字幕条的位置、起止时间和长度；参考明确句界和音频停顿参与分段，保持文本顺序，不擅自替换文字。
- [x] 不把正常多字长句统一截到固定秒数；一两个字或其他短字幕异常拖长时，用可靠语音边界处理，证据不足则标红待复核，不能硬裁掉发声。

## 播放与任务状态

- [x] 空格在非文字编辑状态下只控制播放/暂停，不触发复选框、选择字幕、框选或按钮；文字编辑时正常输入空格。
- [x] “跟随播放”始终开启，移除开关，滚动或切换素材不永久关闭跟随。
- [x] 提前出现、延后消失、最短显示、最长显示默认全部为 0（关闭），迁移旧默认值；后续手动调整仍可保存。
- [x] 成功任务进度必须为 100%，保留完成时间和总耗时；失败或取消不能伪装成功，不再用“等待任务”覆盖成功状态。

## 验证范围

需要后端、前端、浏览器交互及完整离线运行验证。尤其检查：关闭网络后仍可进入界面、无 pip/环境安装子进程、模型下载重试/取消/断点校验、删行后校准不恢复、标点与数字开关、短字与正常长句、空格聚焦在各类控件时的行为、三个模式菜单、完成进度和报告。
