## 暂缓与边界

构建产物暂未清理：`dist/` 旧 EXE、`installer/build/stage-*` 及准备好的运行库属于可重新生成的发布产物，不参与本轮源码清理。模型、工程、缓存和运行环境均保留。`runtime/`、`wheels/`、`tools/portable/` 和 `tools/package_release.py` 仍用于旧便携包及启动验证，保留用途明确的兼容链。

已清理：重复的首次启动依赖脚本、硬编码旧桌面路径的一次性迁移脚本、无入口的单条采用参考函数、旧匹配兼容包装、空白缺句状态/存储字段、重复校验按钮和旧布局样式。详见 [清理记录](修复验证/项目精简_2026-11-12/验证记录.md)。

低收益优化暂缓：匹配 DP 的全排序、波形二进制缓存、拼音逐字回退和重采样延迟补偿。波形聚合现有实现已有基准支持，不为换实现而重写。

不强行修改严重重叠或不可靠音频边界，保留复核标记。持续噪声、音乐和多人重叠仍可能影响 VAD。素材路径、强杀/断电恢复、真实 GPU、五文件批量、剪辑软件导入、多屏 DPI、任务栏固定和屏幕阅读器都需要对应场景实测。

当前自动化通过结果只证明被执行的用例；浏览器合成素材与模拟推理不能视为真实模型准确率验收。
