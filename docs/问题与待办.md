## 暂缓与边界

维护残留（尚未删除）：历史检查的两个旧 EXE 与旧安装暂存副本合计约 169 MB，属于可重新生成的构建产物。发布现已改为在线 EXE，`installer/` 是正式构建源码，必须保留。`tools/restore_from_desktop.py` 依赖旧桌面路径，属于一次性迁移工具。`tools/bootstrap_deps.py` 与当前 bootstrap 职责重复，只被旧发布必需文件清单引用，移除前需同步清单和启动验证。`runtime/` 是在线安装包必需资源；`wheels/` 用于离线包、旧便携包和隔离启动验证，不进入在线 EXE。

低收益优化暂缓：匹配 DP 的全排序、波形二进制缓存、拼音逐字回退和重采样延迟补偿。波形聚合现有实现已有基准支持，不为换实现而重写。

不强行修改严重重叠或不可靠音频边界，保留复核标记。持续噪声、音乐和多人重叠仍可能影响 VAD。素材路径、强杀/断电恢复、真实 GPU、五文件批量、剪辑软件导入、多屏 DPI、任务栏固定和屏幕阅读器都需要对应场景实测。

当前自动化通过结果只证明被执行的用例；浏览器合成素材与模拟推理不能视为真实模型准确率验收。
