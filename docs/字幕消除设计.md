# 字幕消除

开发分支：`feature/subtitle-removal`。保留基线：`main` / `v2.3.5`（`f48e4166`）。源码、EXE、Git bundle 及 SHA256 清单位于 `C:/WeieOuer/Project/releases/SubtitleStudio/v2.3.5`。Git 不跟踪环境、模型、用户数据；这些目录留在原处。没有远程推送。

## 模式与界面

模式顺序：**字幕消除 / 字幕提取 / 字幕对齐**。消除使用自己的视频、选区、任务与结果状态；切换模式不能覆盖已经编辑的字幕。

- 左栏：选择视频、ProPainter 模型与独立 CPU/GPU 环境状态、处理精度和输出位置。只显示本模式需要的参数。
- 中间：视频与真实画面大小一致的框选层，支持重新框选、拖动与缩放；原片/预览结果切换，共用时间位置；留出清晰空状态。
- 右栏：步骤提示、选区像素值、处理时间范围、短片预览、开始消除、取消、真实进度、结果定位和“用于字幕提取”。高级参数折叠，主要操作明确。
- 操作顺序：选视频 → 框选字幕（包含描边）→ 预览 3 秒 → 对比 → 开始消除 → 查看新视频。短片预览和完整输出明确区分。
- 保存原视频，输出另存；音视频分辨率和原时间戳需验证。AI 视频修复会重新编码视频，不宣传“无损恢复”。

## 模型与环境

接入 [ProPainter 官方实现](https://github.com/sczhou/ProPainter)，固定提交及依赖写入 `config/removal.json`。代码、模型与主开发环境分开；模型按需下载，主环境不安装 Torch/图像推理依赖。源文件和权重记录来源与校验结果，就绪必须经过导入自检。

官方模型采用 [NTU S-Lab 非商用许可](https://github.com/sczhou/ProPainter/blob/main/LICENSE)，下载界面显示原许可与来源。8GB 显存不代表可以直接全尺寸修复长片；官方提供的显存数据与分辨率、帧数相关。本机默认局部上下文、512 处理边长和有限帧窗口，实际效果及速度以本机测试为准。

第一版处理用户明确框出的区域及时间范围；不会把整个底部自动当字幕，也不伪装成自动字形检测。无字幕帧仍可能被框区修复影响，应先短片对比。后续增加文字检测模型与逐帧精细掩膜，再评估 STTN 等备用模型，未接入的模型不显示为可用。

## 处理与可靠性

- 归一化选区持久化到独立工程配置；坐标映射排除播放器黑边，拒绝越界、空选区、无视频轨或无效时间。
- 串行任务与现有识别互斥；下载、准备环境、解码、修复、编码、封装分阶段显示。取消只停止自己的工作进程，失败保留明确日志。
- 以有限帧窗口及重叠上下文处理，不一次加载整片；仅把选区的修复像素合成回原帧，其余区域使用原帧像素。逐帧保留 PTS，不把 VFR 强制改成整数帧率。
- 短片预览生成可播放 MP4；完整输出优先 MKV 保留原音轨。MP4 音频兼容性需明确处理，不能静默丢失音轨。
- 先写任务临时文件，成功后原子完成；同名另存，不覆盖输入；取消/失败不把半成品标为成功。
- 任务请求带标识，重复请求复用；结果绑定原视频、选区、范围和参数，修改输入后旧预览失效。断线保留任务标识并允许重新查询。

## 验收

覆盖横/竖屏黑边下坐标、不同缩放、选区编辑、模式切换、模型未安装、下载中断、取消、短片与整片、音轨及 PTS、重名输出、真实模型推理。合成任务测试只验证交互和媒体流程；真实模型用短片单独记录效果、耗时与显存，不能以模拟通过替代。

已有识别长条与词时间问题仍保留在原待办；本功能不等于修复识别算法。
