# 文档索引

当前文档只维护现行规则，各有一个职责：

| 文档 | 内容 |
|---|---|
| [README](../README.md) | 安装、日常使用、打包命令、排错入口 |
| [技术总览](技术总览.md) | 架构、环境、数据、发布和维护约束 |
| [打包与首次启动](打包与首次启动.md) | 完整 EXE 构建、自定义安装目录、打包白名单和首次启动 |
| [流程与界面复查](流程与界面复查.md) | 当前校对流程、已落实的小功能改进、布局与后续建议 |
| [需求与规范](需求与规范.md) | 字幕处理分工、编辑/导出和界面关键行为 |
| [问题与待办](问题与待办.md) | 未完成事项与已知边界 |
| [设计检查与改进建议](设计检查与改进建议.md) | 识别、时长、标签、操作与路径的待实施方案和优先级 |
| [开发记录](开发记录.md) | 重要变更、实际验证与证据链接 |

维护约定：

1. 只修改对应职责的文档，不在多处复制同一功能的完整说明。
2. 开发记录只写结果、原因、兼容性和实际验证；常规调整不再逐文件记流水账。
3. 新问题写入待办，完成后移出待办，在开发记录留结论；测试结果只记录实际运行值。
4. 复杂修复的证据放在 [修复验证](修复验证/README.md)，正文只放链接，不复制日志。
5. 旧长稿已完整保存在 [整合前档案](archive/文档整合前_2026-11-09/清单.json)。[archive](archive/) 和 [versions](versions/) 只作历史参考，不代表当前行为。

接口和依赖的最终依据分别是后端源码、`requirements*.txt`、`config/engines.json`；文档不重复维护完整字段或包版本表。
