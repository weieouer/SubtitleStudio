# 主模型与辅助模型

识别设置保留“模型 / 辅模 / 设备”三行，两个处理模式均显示。下拉框紧凑展示名称；无模型时置灰不可选择，右侧下载按钮仍可操作。悬浮对应文字查看简短说明，不使用问号图标，不展开大段介绍。

## 主模型

| 名称 | 悬浮简介 | 执行引擎 |
| --- | --- | --- |
| Whisper large-v3 | 多语言字幕提取，通用高精度，支持词级时间戳 | faster-whisper |
| Whisper large-v3-turbo | 多语言字幕提取，速度更快 | faster-whisper |
| FireRedASR2-AED | 中文字幕提取，支持词级时间戳 | FireRedAsr2 |
| Qwen3-ASR-1.7B | 中文、方言、多语言识别；当前时间戳为分块估计 | qwen-asr |
| paraformer-zh | 测试模型 | FunASR |

`trabo` 统一使用官方名称 `large-v3-turbo`，`araformer-zh` 使用 `paraformer-zh`。不把“顶级”描述作为跨数据集、跨机器的绝对准确率承诺。

## 辅模

- Qwen3-ForcedAligner-0.6B：下载后将人工确认的当前字幕对齐到视频音轨，不替换文本。
- Silero VAD：faster-whisper 已内置 ONNX 模型，显示已就绪，不重复下载。中间字幕选项区的“仅人声”开关控制提取前的人声检测，不过滤已经识别的疑似字幕，也不在对齐时删除条目。
- FireRedPunc、pyannote 暂不安装。当前标点开关仅保留/去除已有标点，不恢复新标点；当前不自动给字幕添加人物名。

## 下载与环境

只下载固定注册的模型到 `data/models/<名称>`，不允许前端指定任意模型 URL。优先检测国内的魔搭 ModelScope 和 HF-Mirror，分别取真实权重前 256 KiB 做小流量采样，按包含连接时间的样本速度排序；国内源的清单均不可用时再尝试 Hugging Face 官方备用。这个测速只代表当时网络与小样本表现，不保证整个下载过程始终最快。

魔搭对应仓库与主模型命名一致，Paraformer 例外：使用 `iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch`。魔搭按每个文件的提交版本固定链接；HF 镜像按仓库提交版本固定链接。备用文件只有名称、大小、SHA-256 均相同才允许加入切换列表，避免混用版本。清单和采样请求使用 6 秒超时，文件请求使用 12 秒超时。

下载使用临时 `.part`，支持续传、取消与重试；续传检查 Content-Range 的起点和总长度，文件完成后检查大小与可用的 SHA-256。网络失败重试时轮换已验证的备用源。成功后写完整文件清单和来源；损坏或不完整下载不能当作已就绪模型。

下载与安装进度统一显示在原“等待任务”区域，进度条加粗。网络下载显示来源、字节进度和 MB/s；首次依赖准备显示安装阶段，不伪造精确的安装百分比。暂停后保留片段。下载中避免同时启动识别抢占资源。

Whisper 使用主项目虚拟环境。FireRed、Qwen、Paraformer 的依赖分别安装到 `data/engines/<引擎>` 的独立虚拟环境，通过子进程调用，避免 Torch、Transformers、NumPy 版本冲突污染现有识别环境。首次准备可能还需要下载大型运行时包，失败日志保存在该环境的 `install.log`。模型文件已下好但依赖失败时允许重新初始化。

独立环境的 PyPI 依赖使用清华 TUNA 源。FireRed SDK 本身仍取官方 GitHub 发布源码地址，未接入无法确认来源的 GitHub 代理。

Qwen3-ASR 本身的结果在本实现中按音频窗口给出粗时间，并显式标为估计。需要精确时间时使用单独的 ForcedAligner；不自动把额外对齐模型隐含在每次 ASR 下载中。FireRed 和 Paraformer 优先使用 SDK 返回的词/字时间；缺失时间时明确标为估计。

## 来源与验证边界

- [魔搭模型仓库](https://modelscope.cn/models/Qwen/Qwen3-ForcedAligner-0.6B)、[Paraformer 官方模型](https://modelscope.cn/models/iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch)。
- [HF-Mirror 使用说明](https://hf-mirror.com/)：Hugging Face 国内镜像。
- [本机小流量探测记录](修复验证/国内模型源探测.json)：六个模型均成功取到国内清单与权重样本，本轮均选择魔搭；另验证了非空的小配置文件下载与哈希。未执行全量权重下载。

- [faster-whisper](https://github.com/SYSTRAN/faster-whisper)：现有 Whisper 模型和内置 VAD。
- [FireRedASR2S 官方接口](https://github.com/FireRedTeam/FireRedASR2S)：AED 时间戳接口与官方权重。
- [Qwen3-ASR 官方接口](https://github.com/QwenLM/Qwen3-ASR)：ASR 与 ForcedAligner。
- [FunASR 官方模型与接口](https://github.com/modelscope/FunASR)：Paraformer。
- [RapidFuzz](https://rapidfuzz.github.io/RapidFuzz/Usage/fuzz.html) 与 [pypinyin](https://github.com/mozillazg/python-pinyin)：独立文本校验，不需要额外语言模型。

本轮实现和验证下载协议、文件完整性、SDK 适配、进度、取消及界面行为。未自动批量下载所有权重，未声称对所有引擎完成真实长视频推理；真实运行仍取决于模型下载、对应环境安装与可用硬件。
