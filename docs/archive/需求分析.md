# 字幕工作室需求分析 v2（整合与修复后）

更新：2026-11-04。对应应用2.1.0。本文为唯一需求正文，原简版文件保留入口；实现核对与未测范围见[代码审查报告v2](代码审查报告.md)。[v1审查报告](versions/代码审查报告_v1_2026-11-04_修复前.md)保留，不把历史缺陷反例当成当前功能通过。

## 1. 目标与边界

本地视频/音频转字幕工作台：导入→中文识别→校对/剧本建议→声波校时→SRT导出。采用faster-whisper本地模型，不调用云端识别或上传素材到云端；首次安装依赖及准备模型另行完成。

支持媒体、SRT、TXT/MD/DOCX剧本。暂不做声纹分离、多音轨选择、翻译、烧录、自动下载模型、剧本一对多强制对齐、免安装发行。角色来自剧本，不代表识别出了说话人。数字开关属于显示/导出格式，不自动纠错或改写工程原文。

## 3. 流程与模式

| 模式 | 识别开始条件 | 识别后 |
|---|---|---|
| 字幕提取 | 有媒体、可用本地模型 | 识别，按停顿阈值切分，不自动做宽度分段 |
| 字幕对齐 | 上述条件＋已导入剧本 | 识别后匹配剧本，只给建议；人工采用后替换 |

可直接导入SRT跳过识别。无媒体时以SRT路径保存工程，重导同一源文件可恢复。已有媒体时导入SRT属于当前媒体工程的一次可撤销替换。

布局：左栏模式/素材/设置/队列；中间预览/字幕表格/声波；右栏对齐检查。处理中锁定会冲突的编辑、切换和导入；模式说明保持一行，详细说明放在悬浮/聚焦提示。

## 4. 功能规格

### FR-01 素材与路径

点击选择保留原路径；拖入媒体复制到uploads工作目录，输出也在副本旁。支持mp4/mkv/mov/avi/flv/ts/m4v/webm/wmv与mp3/wav/m4a/aac/flac/ogg/opus/wma，扩展名被接受不保证所有编码可播放。

识别固定第一条音轨。媒体与波形加载校验路径/epoch，过期响应忽略；上传可取消，XHR有超时。路径只解码一次。重新拖入会产生新副本路径；移动源文件会改变工程键，暂不自动迁移工程。

### FR-02 本地识别与模型

列出tiny/base/small/medium/large-v3-turbo/large-v2/large-v3，只使用本地找到的模型。当前发现medium、large-v3；发现model.bin不等于完整性或准确率验收。

固定中文、词级时间、beam=5、temperature=0，VAD可关闭。普通话简体提示；并不保证每个汉字独立计时。auto优先可用GPU float16，失败重试CPU int8；cpu强制CPU，cuda强制GPU且不自动降级。PyAV先解码第一音轨为16kHz单声道float32。

### FR-03 任务与恢复

单worker队列；客户端先生成任务ID，后端按ID去重；轮询状态与结果获取分开。断线保留身份、退避重查，不立即允许重复提交；可请求取消。

结果应用核对媒体、epoch和字幕快照；冲突时保留人工修改，提供另行采用结果的入口。解码中可检查取消，模型加载/片段生成等待不是即时可中断。后端进程重启后的在途任务不承诺续跑。

### FR-04 停顿切分

默认0.6秒，0–2秒、0.1步进，0关闭。相邻词间隔达到阈值才拆分；识别后和智能分段时执行。无words的SRT不作停顿切分。

拆分以当前原文切片，保留标点和空白；校对文本无法可靠对应词表时保留整条、提示人工检查，不用旧words重建。来源gap_split。

### FR-05 宽度分段与合并

默认显示宽度20，范围6–30。W/F/A字符计1，其他常规字符0.5，换行0；分词/标点优先，长英文串和附着标点可能超宽，参数不是绝对硬上限。

有词时间时细分；不足时按宽度估算，拆分首尾不超原时段、每片正时长。时段过短时保留原条待检查。合并要求同角色、非负间隔≤0.25秒、合并后≤7秒且不超宽；同步词表或清空估算，清除过期匹配建议。

### FR-06 剧本建议

解析角色:台词、角色（提示）:台词、待确认:台词，过滤场次/音效等；DOCX读正文XML段落。无角色冒号的正文不直接变台词。

SequenceMatcher归一化模糊比较，先向后局部搜索，未命中后可在剩余字幕重新定位；命中索引严格向后、不复用。普通阈值0.34，待确认0.26；匹配提醒与ASR提醒独立。逐条采用或≥75%全部采用可撤销。

这是文字建议匹配，加声波/预览人工校时，不是根据声波直接理解台词的强制对齐算法。

### FR-07 编辑与历史

文字、时间、增删、采用、分段、合并、校时可撤销/重做，常规上限60步；换工程清历史，同工程替换进入历史。时间输入拒绝空值、非法分秒和倒序；预览查找不依赖数组已排序。

支持状态筛选与搜索。ASR待校对阈值confidence<0.45或no_speech_prob>0.5；噪音>0.6；前端低置信筛选另含confidence<0.6。搜索轻微防抖；表格仍非虚拟列表，千条性能待基准测试。

### FR-08 声波与对齐检查

右栏显示剧本、当前字幕、分数和起止，选择联动中间预览及两处声波。声波有时间刻度、播放头、选中区间、缩放；局部窗口≤120秒时定位解码细波形，失败则退回全片峰值。支持单句试听、起止输入、拖动区间边缘校时和撤销；左右键定位，Shift加大步长。

全片峰值分块聚合，默认1200桶、范围100–4000，缓存包含媒体变更信息。ASR全音频内存优化尚未完成。浏览器编码不兼容时不能保证预览/试听成功。

### FR-09 界面与反馈

参数为加长一体刻度输入框。深浅主题为柔和灰蓝，分栏可拖动并持久化；窄屏保留素材/剧本入口。筛选框高度36px，避免文本裁切。

音效默认开、80%，可调0–100和静音，浏览器首次用户操作后解锁；按钮有按压/按键反馈，刻度滴答，识别/导出成功提示。音效本地合成，不下载外部音频。

左上角、网页与Windows app窗口使用胶片图标。窗口几何仍按工作区/DPI计算，真实多屏首次定位待实测。

### FR-10 导出与数字格式

默认媒体同名同目录；拖入素材在工作副本旁；无媒体写outputs。UTF-8无BOM、CRLF，按时间排序重编号，重名用_2等不覆盖。

界面可选排除噪音、补句末标点、阿拉伯数字；不提供角色名开关。数字默认中文，开启后预览/导出用阿拉伯数字，工程与校对原文保留。保守转换明确数词，保护部分人名/成语/型号，歧义口语数字保留人工处理。

导出拒绝空文本、非有限数、负值、起止倒序、超媒体边界及重叠。界面选项只影响呈现/输出，不自动替换当前校对原文。

### FR-11 保存与批量

媒体/SRT绝对路径SHA1前16位生成工程文件，含字幕、剧本、设置、更新时间和revision。前端串行保存；后端线程及跨进程锁、版本冲突检查、原子替换；冲突409时保留编辑，保存失败不换素材。正常编辑1.2秒防抖，配置0.8秒，Ctrl+S两者保存；未保存关页有提示，隐藏时尽力flush。

批量固定本轮设置，逐项加载、核对路径、识别、保存、导出；完成必须有成功输出。导出失败可只重试导出；取消当前任务终止本轮并重绘，后续等待项保留。队列仅内存保存，刷新不恢复；字幕对齐批量要求各媒体工程已有剧本，临时一个剧本不自动分配给所有文件。

## 6. 接口与安全

API要求当前页面会话令牌，校验Host/端口、Origin与跨站来源；媒体video标签通过查询令牌访问流，拒绝跨来源预检。令牌由本机服务随机生成，重启后旧页面需刷新。它不替代操作系统文件权限，也不是完整安全审计证明。

现有health/models/config、media/info/stream、waveform、jobs、srt/parse/export、script/parse/match、segment/merge、projects/save/load、upload、dialog、open_folder等接口保留。新增/调整：

- GET jobs/{id}仅状态，结果用`?result=1`。
- POST jobs支持request_id去重。
- POST projects/save支持source_path与expected_revision；保存返回新revision。
- GET waveform支持start/end局部窗口（≤120秒）。
- 系统文件选择器在独立进程主线程运行，同服务禁止并发多个对话框。
