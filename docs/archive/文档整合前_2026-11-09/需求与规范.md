# 字幕工作室 需求与规范

本文整合自原《字幕工作室_需求分析》《需求分析》《剧本参考字幕反向匹配与校验需求》《UI全局视觉规范》四份顶层文档，作为产品需求与 UI 规范的单一来源。历史版本归档在 `docs/archive/`。

更新：2026-11-09。对应应用 2.3.4。

---

## 一、产品需求

### 1. 目标与边界

本地视频/音频转字幕工作台：导入 → 中文识别 → 校对/剧本建议 → 声波校时 → SRT 导出。采用 faster-whisper 本地模型，不调用云端识别或上传素材到云端；首次安装依赖及准备模型另行完成。

**支持**：媒体、SRT、TXT/MD/DOCX 剧本。

**不做**：声纹分离、多音轨选择、翻译、烧录、自动下载模型、剧本一对多强制对齐、免安装发行。

**角色**：来自剧本，不代表识别出了说话人。

**数字开关**：属于显示/导出格式，不自动纠错或改写工程原文。

### 2. 两种模式

| 模式 | 识别开始条件 | 识别后 |
|---|---|---|
| 字幕提取 | 有媒体、可用本地模型 | 识别，按停顿阈值切分，不自动做宽度分段 |
| 字幕对齐 | 有媒体和字幕 | 按音轨更新起止时间；同一句内明显停顿按阈值拆条（短停顿不拆，0关闭），参考里明确是两句话时按句界分开、不受停顿阈值影响；过长字幕按每行字数分段；短字幕时长按发声字数设上限，用语音活动收紧；导入剧本时另行匹配，只给建议 |

- 可直接导入 SRT 跳过识别
- 无媒体时以 SRT 路径保存工程，重导同一源文件可恢复
- 已有媒体时导入 SRT 属于当前媒体工程的一次可撤销替换
- 模式切换不会改动导入文件
- 对齐模式主按钮同一位置变为“校准字幕”和“对齐字幕”，推荐顺序为“开始校验 → 校准字幕 → 对齐字幕”：开始校验只对照参考标出内容差异（绿=校验通过、黄=疑似、红=明显问题），不改字、不改时间；校准字幕按参考补全漏字、删除多余内容并修正错字和谐音，参考里两句话就分段、一句话就合并，超过每行字数也分段，只改内容、不碰音轨，通过标签变为“校准通过”；对齐字幕用当前字幕文字按音轨校时，同一句内明显停顿按阈值拆条（短停顿不拆，0关闭），参考里明确是两句话时按句界拆开、不受停顿阈值影响，过长字幕再按每行字数分段，只拆不合并，通过标签变为“对齐通过”。疑似和明显问题三个步骤通用；标签只做标注，不自动关闭导出。校准关闭“语气词”时直接删除整条语气词并清理句首、句末语气词，开启时按可靠参考去掉参考中没有的语气词。校准和对齐完成后都弹窗显示处理前后总条数、改动条数和各级数量

### 3. 提取流程

1. 点击选择保留原路径；拖入媒体复制到 `uploads` 工作目录，输出也在副本旁
2. 支持格式：mp4/mkv/mov/avi/flv/ts/m4v/webm/wmv 与 mp3/wav/m4a/aac/flac/ogg/opus/wma（扩展名被接受不保证所有编码可播放）
3. 识别固定第一条音轨
4. 媒体与波形加载校验路径/epoch，过期响应忽略；上传可取消，XHR 有超时
5. 路径只解码一次；重新拖入会产生新副本路径；移动源文件会改变工程键，暂不自动迁移工程
6. ASR：固定中文、词级时间、beam=5、temperature 从 0 起步回退，VAD 可关闭；关闭“语气词”时直接删除整条语气词并清理句首、句末语气词，开启时保留并正常导出
7. 普通话简体提示；不保证每个汉字独立计时
8. 设备：auto 优先 GPU float16 失败重试 CPU int8；cpu 强制 CPU；cuda 强制 GPU 不自动降级。GPU 环境默认不下载，需在界面点击“下载 GPU 环境”按需安装；安装或驱动失败自动恢复 CPU 环境并提示，可重试或改用 auto/cpu，不把 CPU 环境当 GPU 运行
9. PyAV 先解码第一音轨为 16 kHz 单声道 float32

### 4. 对齐与校准流程

1. 保留刚提取的文件与当前字幕，文件栏作为 SRT 输入；支持点击或拖入 SRT
2. “对齐字幕”以当前字幕文字对齐音轨，更新起止时间；同一句内明显停顿按阈值拆条（短停顿不拆，0关闭），有可靠参考时参考里明确是两句话则按句界拆开、不受停顿阈值影响；过长字幕按每行字数分段衔接后面；短字幕的时长按发声字数设上限，被音效、句后杂音或相邻声音拉长时用语音活动收紧，整条被句前特效音带走时按对齐前粗时间附近的语音段重新锚定，证据不足回退对齐前时间并标记；不做剧本参考校验、不合并、不改字词。未拆条目的校验标签不变，拆分出的子条继承原参考区间
3. 剧本不参与强制对齐的文本生成；导入剧本时可另行匹配参考，只给建议
4. 点击“对齐字幕”后，Qwen3-ForcedAligner 只更新当前时间轴，保留原始时间，可撤销
5. “校准字幕”按参考补全漏字、删除多余内容，修正错字和谐音，并整理明确句界与每行字数分段；参考中两句话被识别成一条字幕时，按参考句界（换行或句末标点）自动拆开；可靠参考中同属一句的相邻字幕，在合并后不超每行字数、且两条之间的停顿未达阈值时自动并回一条，参考里明确是两句话的保持分开、停顿阈值不参与；其他疑似拆出的短碎片只标红“建议合并”，由用户勾选相邻字幕后手动合并；校准不碰音轨，拆分合并后的时间是暂定值，留给最后“对齐字幕”按音源重算
6. 校准和对齐结束后刷新标签：校准只刷新本次处理的条目并变为“校准通过”，对齐刷新全部字幕为“对齐通过”；疑似/明显问题三关通用，对齐失败作为时间问题标出。标签只做标注，不自动关闭导出；旧版本自动加上的排除在再次执行三关时解除，手动“不导出/加入导出”、语气词和幻觉规则保持原样。再弹窗报告处理前后的总条数、改动条数、通过/疑似/明显问题数量；“改动”按原条目的文字与起止时间逐条核对，拆分和改字都计入
7. 音轨对齐按原粗略时间划分不超过约 4 分钟的窗口，保留边缘余量
8. 大幅错位应先粗调，不把局部精确对齐宣传为整集任意错位搜索
9. 当字幕切在一个模型词元内部时，词内分配边界标为估计

### 5. 导出 SRT/MKV

#### 5.1 SRT 导出

- 默认媒体同名同目录；拖入素材在工作副本旁；无媒体写 `outputs`
- UTF-8 无 BOM、CRLF，按时间排序重编号，重名用 `_2` 等不覆盖
- 界面可选：排除噪音、补句末标点、阿拉伯数字、字幕换行；不提供角色名开关
- 数字默认中文，开启后预览/导出用阿拉伯数字，工程与校对原文保留
- 保守转换明确数词，保护部分人名/成语/型号，歧义口语数字保留人工处理
- 导出拒绝空文本、非有限数、负值、起止倒序、超媒体边界及重叠
- 显示时间可统一调整：提前出现、延后消失各 0–1 秒；最短显示 0–10 秒，最长显示 0–30 秒，0 为关闭
- 短字幕延长到最短时长，超长字幕截断到最长时长；两者都以本条的提前/延后结果为基准，遇到下一条开始或媒体结尾即停止，不重叠
- 提前/延后及最短/最长显示时间只影响预览和音轨，不改工程中的字幕时间；导出使用编辑区当前起止值及SRT标准毫秒格式。文字仍按标点、数字、换行设置导出。
- 导出始终包含全部未标记“不导出”的字幕；勾选、搜索和筛选不限制导出范围。

#### 5.2 数字格式

- "阿拉伯数字"默认关闭：预览/导出使用中文数字
- 开启后转换明确数词为阿拉伯数字
- 校对表和工程保留原文，切换可还原
- 人名、成语、型号和有歧义口语数字尽量不转换
- 这是格式呈现，不是识别纠错

### 6. 功能规格（要点）

#### FR-01 素材与路径

- 点击选择保留原路径；拖入媒体复制到 `uploads` 工作目录
- 支持视频/音频多种扩展名（被接受不保证所有编码可播放）
- 识别固定第一条音轨
- 媒体与波形加载校验路径/epoch，过期响应忽略
- 路径只解码一次；重新拖入会产生新副本路径

#### FR-02 本地识别与模型

- 列出三个主模型（FireRedASR2-AED / Whisper large-v3 / Qwen3-ASR-1.7B），只使用本地找到的模型；中文对白优先 FireRed，外语或中英混排优先 Whisper，方言优先 Qwen
- 固定中文、词级时间、beam=5，主解码 0 度；复读或低置信时按 0.2～1.0 升温重试
- 普通话简体提示；不保证每个汉字独立计时
- 静音处词时间异常的片段按幻觉丢弃；连续三条以上相同字幕只标“需复核”，不自动删除
- 整条只有笑声、叹气、咂嘴或“嗯、啊、呀、哼、呵”等填充音的字幕，“语气词”关闭（默认）时在提取阶段直接删除；对白句首、句末及句末标点旁的“啊、呀、哎、唉、哈哈”等独立语气词也一并去掉。整条语气词在开启“语气词”后保留、标记并正常导出；校准仍按可靠参考删除参考中不存在的语气词。对话里句中的“你呀，就是……”和“呢、吗、吧”等语法助词保留，夹在句子里的笑声不过筛；手动“加入导出”的条目不自动删除，手动改字或手动切换导出以人工决定为准
- 设备：auto/cpu/cuda
- PyAV 先解码第一音轨为 16 kHz 单声道 float32

#### FR-03 任务与恢复

- 单 worker 队列；客户端先生成任务 ID，后端按 ID 去重
- 轮询状态与结果获取分开
- 断线保留身份、退避重查，不立即允许重复提交；可请求取消
- 结果应用核对媒体、epoch 和字幕快照；冲突时保留人工修改
- 解码中可检查取消，模型加载/片段生成等待不是即时可中断
- 后端进程重启后的在途任务不承诺续跑

#### FR-04 停顿切分

- 默认 0.6 秒，0–2 秒、0.1 步进，0 关闭
- 相邻完整词之间的停顿达到用户设置阈值才拆分；独立短话合计未超字数也按此规则分开；完整词语仍保护。识别、对齐字幕时执行；校准整理用停顿判断同一句的相邻字幕是否自动合并或标“建议合并”，不在校准内按词间停顿拆条；对齐按停顿拆条，0为关闭
- 无 words 的 SRT 不作停顿切分
- 拆分以当前原文切片，保留标点和空白
- 校对文本无法可靠对应词表时保留整条、提示人工检查，不用旧 words 重建
- 来源 `gap_split`
- 提取、本段重识别和对齐字幕使用同一停顿阈值；0.1秒边界使用浮点容差。对齐只按停顿拆独立字幕条，不按每行字数拆条；“0”为关闭，不参与拆条。改值会按现有可靠词时间重新切分当前字幕，支持撤销；关闭或增大阈值不自动合并已分段条目，避免破坏人工修改。
- 宽度分段保留可核对的词时间；若切在词内，标记估计。切在真实词间停顿时保留空档，不用中点填满静音。
- 自适应底噪死区只用于声学边界判断，不置零原始样本、不删除轻声识别内容。有词时间及明确尾部静音证据时允许收紧拖长的尾部，并保留原时间、标待复核；证据不足保留原边界。
- 缺少词时间、单个词跨越整段停顿或词表与人工文本不符时，不按时长比例猜测文字分配；提示先音轨对齐或人工检查。

#### FR-05 宽度分段与合并

- 默认显示宽度 20，范围 6–30
- W/F/A 字符计 1，其他常规字符 0.5，换行 0
- 按完整词、字数和停顿选断点，优先长度均衡；只有词本身超限时允许词内硬切。手动分段在中间附近切开当前文本，不复制全文、不将尾部拼入下一条原字幕。
- 有词时间时细分；不足时按宽度估算，拆分首尾不超原时段、每片正时长
- 时段过短时保留原条待检查
- 手动合并要求两条或多条连续相邻字幕：文字按原顺序直接拼接（前一条在前），时间取第一条开始到最后一条结束；保留全部 ASR 来源，可一次撤销。非连续多选拒绝合并。
- 校准只对可靠参考中同属一句的相邻字幕自动合并：合并后不超每行字数、两条之间停顿未达阈值、无手动拆分和导出状态冲突时直接并回一条；参考里以换行或句末标点明确分开的两句话不合并，停顿阈值不参与。其余单字或双字短碎片只有在完整词跨界、共同原句或同句相邻可靠参考证据成立时才标红“建议合并”，遵守宽度、停顿阈值、手动拆分和导出状态边界；用户勾选相邻条目后手动合并。
- 保留可映射词时间，缺失时标记估算；可靠参考区间可继承，不可靠时只重匹配新子条及必要邻文。“已分段”仅用于原句超限的实际宽度拆分。

#### FR-06 剧本建议（旧角色格式，已被全文反向匹配取代）

- 解析角色:台词、角色（提示）:台词、待确认:台词，过滤场次/音效等
- DOCX 读正文 XML 段落
- 无角色冒号的正文不直接变台词
- 旧 SequenceMatcher 已废弃，统一转到 `reference_match.py` 全文匹配

#### FR-07 编辑与历史

- 文字、时间、增删、采用、分段、合并、校时可撤销/重做，常规上限 60 步
- 换工程清历史，同工程替换进入历史
- 时间输入拒绝空值、非法分秒和倒序
- 预览查找不依赖数组已排序
- 支持状态筛选与搜索
- ASR 待校对阈值：confidence < 0.45 或 no_speech_prob > 0.5；噪音 > 0.6；前端低置信筛选另含 confidence < 0.6
- 搜索轻微防抖；表格仍非虚拟列表，千条性能待基准测试

#### FR-08 声波与对齐检查

- 右栏显示剧本、当前字幕、分数和起止，选择联动中间预览及两处声波
- 声波有时间刻度、播放头、选中区间、缩放
- 局部窗口 ≤ 120 秒时定位解码细波形，失败则退回全片峰值
- 支持单句试听、起止输入、拖动区间边缘校时和撤销
- 左右键定位，Shift 加大步长
- 全片峰值分块聚合，默认 1200 桶、范围 100–4000
- ASR 全音频内存优化尚未完成

#### FR-09 界面与反馈

- 参数为加长一体刻度输入框
- 深浅主题为柔和灰蓝，分栏可拖动并持久化
- 窄屏保留素材/剧本入口
- 筛选框高度 36px，避免文本裁切
- 音效默认开、80%，可调 0–100 和静音
- 浏览器首次用户操作后解锁；按钮有按压/按键反馈，刻度滴答
- 音效本地合成，不下载外部音频
- 左上角、网页与 Windows app 窗口使用胶片图标
- 帮助对话框顶部显示“字幕工作室”、当前版本、作者邮箱 weieouer@gmail.com 和“未经授权不得商用”声明

#### FR-10 导出与数字格式

见上文 5.1、5.2。

#### FR-11 保存与批量

- 媒体/SRT 绝对路径 SHA1 前 16 位生成工程文件
- 工程含字幕、剧本、设置、更新时间和 revision
- 前端串行保存；后端线程及跨进程锁、版本冲突检查、原子替换
- 冲突 409 时保留编辑，保存失败不换素材
- 正常编辑 1.2 秒防抖，配置 0.8 秒，Ctrl+S 两者保存
- 未保存关页有提示，隐藏时尽力 flush
- 全选跨搜索及筛选勾选全部字幕，包括“不导出”条目；选择仅用于编辑，不改变导出标记。
- 删除、导出标记、校准字幕支持批量和全选；校准字幕有选择时处理选中，未选择时处理全部，不限制10条，缺失或过期参考内部局部刷新，可靠错字/谐音/漏字/多字和多余内容才改写，无参考和歧义保留并提示。可靠参考中同属一句的相邻字幕在宽度和停顿允许时自动合并；其余疑似拆出的单字/双字碎片只标红“建议合并”，不自动改字或合并。大批校验自动分请求，单请求最多5000条（含必要上下文）。
- 编辑排固定“合并、分段、添加、删除、撤销、重置”；处理排固定“关闭导出、重新识别、校准字幕、对齐字幕”。提取模式隐藏后两项。推荐顺序为“开始校验 → 校准字幕 → 对齐字幕”：校准字幕按参考补全漏字、删除多余内容，参考里两句话被并成一条时自动拆开（不碰音轨，时间留给对齐字幕），再按每行字数、标点和数字设置整理内容；对齐字幕作用于全部当前字幕，更新起止时间并按停顿阈值拆条（0关闭），不按每行字数拆条、不合并、不改字词。移除独立采用、校验和完成小按钮。
- 校验只打标签不改字；一般疑点黄“疑似问题”，参考中不存在的内容和其他明显异常红“明显问题”，通过标签随最后一次检查变化（校验通过 / 校准通过 / 对齐通过）。手改文字后绿“修改完成”，隐藏旧疑点；对齐只改时间，不会让修改确认失效。重新校准或重新校验可用新结果替换修改确认。标签只做标注，不自动关闭导出；手动“不导出/加入导出”、仍保留的语气词和确认幻觉的排除保持原样。不显示“已完成”“待重新校验”。
- 重识别支持多选和全选，不限条数，从后往前逐条处理，避免拆条后索引漂移；取消或失败停止余下条目，已完成部分保留，整批可一次撤销。队列仅内存保存，刷新不恢复。

## 二、剧本参考字幕反向匹配与校验需求

### 1. 输入与责任边界

- 以 ASR 字幕为主体，输入字幕序号、原文、开始/结束时间及原始识别记录
- 原始 TXT 剧本只作参考，允许任意排版，不要求人物名、冒号、引号或对白格式
- 兼容现有 MD、DOCX 导入
- 支持一次多选、多文件拖入、分次追加剧本，严格按导入顺序以换行拼接全文，与视频对白顺序一致；素材槽显示最后一份文件名及 `×N`，悬浮列出导入顺序。清除按钮移除全部剧本。
- 工程保存完整合并原文及 `script_names` 文件名顺序，旧工程按单份恢复。追加或清除剧本使旧匹配建议和旧撤销历史失效，须重新校验后采用。
- **识别、文本校验、人工确认、校准和音轨强制对齐是相互独立的步骤**
- 文本匹配不调用 Whisper、Qwen 或任何大语言模型，不听音频，不宣称能判断视频实际说了什么
- 剧本与成片有差异时，交由人工结合试听判断

### 2. 不可变数据与标准化

- 保存剧本完整原文、非空段落、原始字符起止位置和物理行号
- 空行和 CRLF 保留在全文中
- 使用 NFKC 统一全半角、兼容字符，统一大小写
- 删除标准化副本中的标点、空白及无意义特殊字符
- 标准化按 Unicode 字簇进行；每个输出字符保存对应原始字符半开区间
- 一对多字符转换和组合附加符号不会丢失来源
- API 位置以 Python Unicode 字符索引为单位，零基、结束位置不包含
- 界面显示一基位置和段落编号
- 每条字幕保留 `asr_original / original_text / original_start / original_end`
- 人工操作只改当前文本或当前时间，不改原始记录
- 原始视频、音轨、剧本和导入 SRT 不被覆盖；拖入的文件保存为工作副本

### 3. 全文反向搜索

实现文件：`backend/core/reference_match.py`

1. 为完整剧本建立标准化文本、字符位置映射、字符二元组及拼音二元组索引
2. 每条当前字幕独立搜索，并组合相邻 1–4 条字幕辅助搜索；组合受时间间隔限制
3. 从精确命中、二元组锚点和全文模糊搜索获取候选，在局部滑动窗口中调整片段起点与长度
4. RapidFuzz 提供字符相似度，pypinyin 提供不带声调的拼音序列相似度
5. 综合分增加长度差惩罚，避免过短截取片段抢占正确整句
6. 使用按字幕时间推进、记录各 source 独立末尾位置的动态规划与有限束搜索选择组合
7. 同一文件内候选不能逆序或重复占用；允许跨文件切换及返回，导入顺序不限制视频演出顺序；未匹配条目不会阻断后续定位
8. 一条字幕可跨连续段落；多条字幕可对应同一参考段落，使用字符对齐映射将参考内容分配给各条
9. 重复台词的其他位置保留为候选，结合前后锚点判断
10. 仍无法唯一确认时显示多候选，不自动采用
11. 以前后唯一长台词锚定局部区间；中间1–3条无法在局部对应时显示红色“疑似多余台词”。全文其他位置的同句只作参考候选，不可自动采用。缺少可靠邻文或存在真实连续/反复来源切换时保守处理，不把文本校验当成音频真值。
12. 只校验部分字幕时携带前后各3条邻文和原始顺序号，只更新目标条目；不连续的选择不得伪装成相邻上下文。

**边界**：全局保留64条路径，每个活跃来源补充8条，总上限256；这是有计算边界的多来源顺序搜索，不宣称等价于穷举全部组合的数学全局最优。长稿件应按集处理。多份剧本合计上限 50 万字符、每次最多 5000 条字幕、单条最多 1000 字。

### 4. 分数与阈值

- 字符分、拼音分、综合分均为 0–1，界面以百分比显示
- 默认综合分以字符为主、拼音权重 0.25，拼音权重不得超过 0.4
- 拼音相同不会自动更正汉字
- 可配置参数（默认值）：
  - 最低分 0.64
  - 高分参考线 0.94
  - 拼音相似门槛 0.90
  - 候选分差 0.035
  - 组合条数 3
- 1–3 字短句最低门槛至少 0.88，4–8 字也适当收紧
- **分数不是识别正确率**：即使分数很高，只要有实质字符差异，仍显示对应疑点

### 5. 拼音 + 字面匹配

- RapidFuzz：字符相似度
- pypinyin：不带声调的拼音序列相似度
- 综合分 = 字符分 × (1 − 拼音权重) + 拼音分 × 拼音权重 + 长度差惩罚
- 拼音权重默认 0.25，上限 0.4
- 拼音分高于字符分且达到门槛时标"疑似谐音"，仅作疑点
- 拼音相同不会自动更正汉字

### 6. 相邻组合

- 组合 1–4 条相邻字幕辅助搜索
- 组合受时间间隔限制
- 候选不能逆序、不能重复占用同一段参考文字
- 未匹配条目不会阻断后续重新定位

### 7. 同音字纠正

- **不自动纠正**：拼音相同不会自动更正汉字
- 拼音分高于字符分且达到门槛时标"疑似谐音"
- 仅作疑点提示，由人工采用/保留/修改

### 8. 校验状态与上下文提醒

| 状态 | 含义与处理 |
|---|---|
| 高度匹配 | 标准化后相同；不代表已经听音确认 |
| 疑似错字 | 存在替换差异，人工核对 |
| 疑似谐音 | 拼音分高于字符分且达到门槛，仅作疑点 |
| 疑似漏字 | ASR 相对参考存在插入位置，不自动补字 |
| 疑似多字 | ASR 相对参考存在删除位置，含重复字疑点 |
| 未匹配 | 无可靠参考、位置冲突或疑似叙述片段 |
| 多候选匹配 | 多个位置在可接受分差内，需确认参考位置 |
| 疑似多余台词 | 前后文已定位，当前局部片段无可靠对应；字幕及标签标红，别处同句只作只读线索，不自动删除 |

- difflib 提供差异区间和字符：原字幕侧标出疑似错字/多字，参考侧标出对应文字/疑似缺少文字
- 标点和空白差异不作为汉字错误
- 场次、动作、镜头等明确说明使用规则标记为仅供参考，不能直接作为可采用的对白建议
- 任意无格式叙述与对白之间不存在纯文本算法能够保证的语义分界，所有普通片段只被称为"参考"
- 匹配位置之间未覆盖的剧本内容单独列作核查提示，可能为叙述、剪辑差异或 ASR 遗漏，不生成额外字幕，也不编造时间

### 9. 右侧逐条双栏对照

右栏按 ASR 字幕序号连续排列，每条占一张卡片，可一直向下滚动：

- **左列**：ASR/导入原文、当前字幕、原始时间戳
- **右列**：对应剧本原文、段落范围、字符位置
- **卡片下部**：字符分、拼音分、综合分、差异字符说明、其他候选
- 点击卡片定位表格和预览；可试听当前句

当前主要操作：人工修改、校准字幕、对齐字幕；导入剧本后生成校验结构，不再单独放采用、校验和完成按钮。历史候选确认数据保留兼容。

- 多候选必须先确认位置，才允许采用
- 不可靠或明确叙述候选不可直接采用
- 采用是明确的人工操作，支持撤销/重做
- 取消自动批量采用高相似文字
- 改动当前文本后标记结果过期，重新匹配前禁止直接采用旧建议
- 跳过和非剧本标记在普通重新匹配时保留，单条重新匹配可解除标记
- 项目保存完整剧本、原始 ASR、当前字幕、校验结果及人工决定

- 已对齐以成功的音轨强制对齐记录为准
- 疑似包括噪音标记、低置信、剧本匹配待复核
- 各条只计一次，筛选不改变总统计

### 4.1 疑似幻觉字幕（自动检测）

- 提取、对齐、打开工程和导入 SRT 后自动检测，不提供单独的“检测全文”按钮
- 固定套话（片尾点赞订阅、字幕组声明等）同时伴随时长或语速异常，或“时长 ≥20 秒且 ≤0.25 字/秒”的极端稀疏条目：标记为确认幻觉，默认 `exclude_export` 并变灰，不进入预览和导出，可手动恢复
- 其他可疑条目只显示“疑似幻觉·待确认”徽标，仍正常导出，由用户试听判断
- 用户改字、选择“纳入导出”后解除提示；重新识别本段时不沿用上一段的幻觉排除，只保留手动“不导出”

### 5. theme-color 适配窗口标题栏

- 左上角、网页图标及 Windows app 窗口使用同一胶片图标；统一为黑白实体图形，外围透明，不再使用色块方图
- 胶片框为黑色，片窗和八个小孔为不透明白色，播放三角为黑色；画面内不做镂空，任何背景上都不透出底色
- 左上角不再按主题反相，深浅两种界面显示同一图标
- `theme-color` meta 适配浏览器标题栏与 Windows 窗口标题栏颜色
- Windows 窗口使用胶片图标和单独任务栏身份（AppUserModel）
- 图标由 `tools/generate_icon.py` 从同一几何形状独立生成 16/20/24/28/32/40/48/56/64/72/80/96/128/256 像素 PNG 帧，矩形边缘对齐目标像素；按窗口 DPI 读取系统小/大图标尺寸，避免固定 16/48 导致二次缩放。Windows 使用 `studio-film-taskbar.ico` 以避开旧资源路径缓存
- 已验证图标资源和 Windows 图标句柄/任务栏属性写入
- 现有固定快捷方式缓存图标的表现需实际桌面检查

### 7. 布局

- 启动窗口按屏幕降一档居中打开
- 2K 屏幕使用 1920×1080 物理像素窗口，系统缩放按 DPI 换算
- 启动时左右栏等宽，不恢复旧版不对称栏宽
- 最大化后两边扩到允许上限（各 520 CSS 像素，同时给中间保留至少 460 像素和分隔线空间）
- 还原窗口重新对称
- 之后仍可手动拖动分隔线
- 窄屏按响应式布局排列
- 布局：左栏模式/素材/设置；中间预览/字幕表格/声波；右栏对齐检查
- 中间栏预览只占剩余高度：竖屏视频按原比例缩放、四周留黑边，窗口变矮时预览先收缩，不把下方字幕限制、时间轴挤出可见区域（中间栏自身不滚动）
- 字幕编辑工具栏：第一排合并/分段/添加/删除/撤销/重置，第二排关闭导出/重新识别/校准字幕/对齐字幕；对齐模式显示后两项，无剧本也能提示无参考。按钮均分宽度、高度至少30px、字号12px。全选和选中提示放标题行，完整说明保留在data-tip。
- 处理中锁定会冲突的编辑、切换和导入
- 模式说明保持一行，详细说明放在悬浮/聚焦提示

### 8. 选项命名规则

- 统一用正向命名："阿拉伯数字"勾选即使用阿拉伯数字
- “标点符号”开启只显示问号、感叹号，不显示逗号和句号等普通标点；关闭连问叹号也隐藏。字幕框、参考/候选、预览、音轨、SRT/MKV导出同步；数字内部3.5、12:30、%‰及英文词内连接符不受影响。校准按此开关整理内容：开启从可靠同字参考恢复语气标点，关闭去掉全部标点；不以疑似/歧义参考猜语气。切换不改原始ASR记录；关闭时编辑保留未改动区原隐藏标点。
- 校准完成后，先对可靠参考中同属一句的相邻字幕自动合并：合并后不超每行字数、两条之间停顿未达阈值、无手动拆分和导出状态冲突时并回一条；参考里明确是两句话的保持分开，停顿阈值不参与。随后在所选连续条目内检测其余误拆单字/双字碎片；需完整词跨界、共同原句或同句相邻可靠参考证据，遵守宽度、停顿阈值、手动分段和导出状态边界。未能自动合并的碎片条文字和“建议合并”徽标显示为红色；用户多选连续相邻条目点“合并”后，文字按前后顺序拼接，时间取第一条开始到最后一条结束。明确完整句界先分成独立字幕，再隐藏普通标点并按每行字数整理；校准内不按词间停顿拆条；无可靠词时间时新分句标估计。无参考/上下文明显问题不因格式整理自动变绿，原ASR和整批撤销保留。
- "字幕换行"勾选时按每行字数保留/生成条内换行，取消则合并为单行，预览和导出一致，不会重新分条或改变时间戳
- 字幕文字格式使用同一套设置计算预览、音轨显示和导出；时间显示限制仅用于预览和音轨，导出保持编辑区当前起止值；停顿切分及明确静音收尾写入的边界优先于提前/延后/最短显示，避免重新填满空档。原编辑文字及时间保留，显示限制不改写原始记录。
- 任务或导入处理中禁用会冲突的字幕限制控件；“仅人声”是提取前的VAD选项，“语气词”控制整条语气词是否保留、提取和校准时是否直接删除，两者在音轨对齐模式置灰，保留其设置供切回提取和重新识别使用。
- 右侧列表顶部固定显示一行“字幕 / 参考”，各字幕卡片不再重复标题；编辑框仍提供逐条无障碍名称。
- 详细含义悬浮在对应选项文字上查看
- 旧工程的单行选项反向迁移，保持原有导出行为

### 9. 已移除的设置

- 排除疑似噪音字幕：已移除，疑似条目正常提取、对齐、显示和导出，状态仅作复核提示
- 补句末标点：已移除（标点开关只控制保留或去除，不补句末标点）
- 角色名：已移除（当前不自动给字幕添加人物名）
- 批量队列：已移除（提取字幕与打开文件夹并排）
- 跳过空字幕/识别空字幕：已移除，不提取、不导出空文本条目；正常识别的空白处保持空档

### 10. 素材区与参数区

- 视频/音频与剧本卡片等宽，网格列允许收缩；长文件名、导入提示和时长/分辨率/大小信息在卡片内部向下换行，高度随内容增长，不横向挤压相邻卡片。

- 素材区"提取字幕"是唯一的识别启动入口
- 使用当前设置一键识别并生成 SRT
- 参数区不再放重复的"开始识别"，仅显示任务进度和执行中的取消/暂停按钮
- 空闲时隐藏取消按钮
- SRT 导出只输出当前字幕，不重复运行识别
- 模型下拉与设备框左右对齐，尽量使用标签右侧空间
- 选项只放名称、状态和独立下载按钮

### 11. "仅人声"位置

- 位于中间"字幕选项"区域
- 与标点符号、字幕换行、阿拉伯数字并列
- 左侧不再重复放置人声检测
- 此开关沿用 VAD 设置和保存逻辑
- 控制提取前的语音区间检测
- 不分离背景音，不删除已识别的疑似条目

### 12. "语气词"位置

- 位于中间“字幕限制”区域，与“仅人声”相邻
- 默认关闭，随设置记忆；音轨对齐模式置灰
- 关闭时提取和校准直接删除整条笑声、叹气、咂嘴或填充音，并去掉对白句首、句末及句末标点旁的“啊、呀、哎、唉、哈哈”等独立语气词；不删除句中“你呀，就是……”、引号内对白和“呢、吗、吧”等语法助词
- 开启时保留整条语气词并正常导出；校准仍会按可靠参考删除参考中不存在的语气词。手动“加入导出”的条目不自动删除；手动“不导出”、手动改字或手动切换导出后，以人工决定为准

## 四、验收重点

### 1. 剧本参考校验

验证：无固定格式剧本、Unicode 位置保真、跨段参考、多条组合、错字/谐音/漏字/多字、重复台词多候选、顺序不交叉、未匹配后重新定位、跳过与重新匹配、原文与时间不被校验修改、人工采用/保留/修改/撤销、文件拖入及保存恢复。

### 2. 文本匹配

- 文本校验使用真实后端进行专项测试
- 模型下载的传输/续传/取消通过小文件和模拟响应验证
- 没有下载并评测所有多 GB 模型
- 不能据此声称五个实模型在本机均已完整推理通过

### 3. 边界声明

- 分数不是识别正确率
- 文本匹配不听音频，不判断视频实际说了什么
- 任意格式剧本中的叙述和对白无法仅凭模糊分数完全区分
- 所有参考修正仍需人工确认
- 依赖与模型说明见 [技术总览.md](技术总览.md)
- 问题与优化见 [问题与待办.md](问题与待办.md)
