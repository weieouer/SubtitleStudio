## 安装包建议

建议发布时用目录式应用载荷加 Inno Setup，交付给用户仍是一个安装 EXE。优先保证安装、卸载、升级和用户数据保留，再考虑其他打包优化。不要把数GB模型塞进每次更新包，也不要把当前电脑的 .venv 直接当作可迁移运行环境。

当前 data 和 config 都在程序根目录。安装到 Program Files 前必须调整可写数据目录；外部 SDK 使用 venv 和 pip，冻结打包后不能直接假定 sys.executable 仍是普通 Python。此轮未开始构建安装程序。

## 精度边界

可以提高混合音轨下字幕的时间准确性，但不能保证音效、音乐和对白叠加时每个字100%准确。波形、RMS、频谱变化和 VAD 都不能单独证明某个字已经开始发音。应以识别文字及强制对齐为主，必要时用人声分离辅助和人工试听校对。

当前已运行 ASR，Qwen 依赖安装尚未完成，不能声称精准对齐链路已完整实测。新增保护只保证 RMS 不会再把起点提前到模型文字时间之前，不保证消除原 ASR 本身的提前误差。
