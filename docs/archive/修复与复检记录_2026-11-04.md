## 复现

在项目根目录：

```powershell
.\.venv\Scripts\python.exe tests\run_backend_checks.py
.\.venv\Scripts\python.exe tests\asr_smoke.py
.\.venv\Scripts\python.exe -m compileall -q backend tests tools
```

前端和数字格式为 Node 标准库测试，没有第三方依赖；本次由 Node 工具环境运行，本机终端未安装 node。已有 Node 的终端可执行：

```powershell
@'
import fs from 'node:fs/promises';
import {runFrontendTests} from './tests/frontend_regressions.mjs';
import {runNumberTests} from './tests/numbers_regressions.mjs';
const ui = await runFrontendTests(await fs.readFile('frontend/js/app.js', 'utf8'));
const numbers = runNumberTests(await fs.readFile('frontend/js/numbers.js', 'utf8'));
console.log(JSON.stringify({ui, numbers}, null, 2));
if (!ui.all_passed || !numbers.all_passed) throw new Error('regression failed');
'@ | node --input-type=module
```

页面测试先在一个终端启动隔离服务：

```powershell
.\.venv\Scripts\python.exe tests\serve_fixture.py
```

读取输出的 url，在另一个终端运行下面命令，将示例端口替换为实际端口：

```powershell
.\.venv\Scripts\python.exe tests\browser_smoke.py --url http://127.0.0.1:12345
```

该测试仅针对上述临时服务，要求本机安装 Chrome；不要把正式服务地址传给它。图标从原生矢量形状生成，重建命令为 `.\.venv\Scripts\python.exe tools\generate_icon.py`。
