# 全局 UI 视觉规范

按界面层级，而不是页面纵向位置分配明暗。中间工作区最深；顶栏和左右栏共享同一档面板色，形成从两侧延伸的框架。相同类型的卡片、控件和选中块共享颜色。

| 层级 | 深色模式 | 用途 |
| --- | --- | --- |
| 最底层 | `#111111` | 中间工作区和布局空隙 |
| 面板层 | `#181818` | 顶栏、左右连续面板 |
| 卡片层 | `#1f1f1f` | 素材、设置、导出、表格、校验卡片 |
| 下陷控件 | `#181818` | 输入、选择、素材槽 |
| 按钮层 | `#2d2d2d` | 全局中性灰按钮 |
| 选中层 | `#373737` | 字幕模式、主题切换、表格与侧栏选中项 |
| 强调 | 低饱和蓝 `#7f9fc5` | 勾选、键盘聚焦、拖入与选中边框 |

浅色模式采用灰底 `#dedede`、面板 `#e8e8e8`、卡片 `#f7f7f7`、控件 `#eeeeee`，同样保留层级差异，避免大面积纯白或相邻灰度过于接近。按钮保持白灰色。

深色模式参考用户提供的 VS Code 深黑层次，所有大面积底色与普通文字均为中性灰 RGB，不使用暖黄色底色或文字。正文 `#dedede`、次级文字 `#b8b8b8`；黄色仅用于待复核或警告状态。

素材未导入时的边框、SRT 文件标记、剧本图标均为中性灰。选中和聚焦才使用淡蓝高亮；状态错误/警告/完成使用对应语义色。

统一使用 `Microsoft YaHei UI / Microsoft YaHei / PingFang SC / Segoe UI / system-ui` 字体链。按钮、输入、表格、下拉菜单、标签、说明、时间戳和 Canvas 标尺共用；时间戳使用等宽数字特性，不再单独切换 Consolas。

按钮采用较低高度、无反光渐变、无凸起阴影；按压反馈轻微。主题与字幕模式切换共用选中背景。全局取消问号图标，直接悬浮或键盘聚焦对应文字、选项查看说明，不为说明额外增加视觉元素。

取消批量队列，提取字幕与打开文件夹并排。模型下拉与设备框左右对齐，尽量使用标签右侧空间，选项只放名称、状态和独立下载按钮。

素材区“提取字幕”是唯一的识别启动入口，使用当前设置一键识别并生成 SRT。参数区不再放重复的“开始识别”，仅显示任务进度和执行中的取消/暂停按钮；空闲时隐藏取消按钮。SRT 导出只输出当前字幕，不重复运行识别。

启动窗口按屏幕降一档居中打开，2K 屏幕使用 1920×1080 物理像素窗口，系统缩放按 DPI 换算。启动时左右栏等宽，不恢复旧版不对称栏宽；最大化后两边扩到允许上限（各 520 CSS 像素，同时给中间保留至少 460 像素和分隔线空间），还原窗口重新对称。之后仍可手动拖动分隔线。窄屏按响应式布局排列。

选项统一用正向命名：“阿拉伯数字”勾选即使用阿拉伯数字；“字幕换行”勾选即保留条内已有换行，取消则合并为单行，不会重新分条或改变时间戳。详细含义悬浮在对应选项文字上查看。旧工程的单行选项反向迁移，保持原有导出行为。

“仅人声”位于中间“字幕选项”区域，与标点符号、跳过空字幕、字幕换行、阿拉伯数字并列；左侧不再重复放置人声检测。此开关沿用 VAD 设置和保存逻辑，控制提取前的语音区间检测；不分离背景音，不删除已识别的疑似条目。

移除“排除疑似噪音字幕”。疑似条目正常提取、对齐、显示和导出，状态仅作复核提示。底部显示“共 N 条 · 已对齐 N 条 · 疑似 N 条”：已对齐以成功的音轨强制对齐记录为准；疑似包括噪音标记、低置信、剧本匹配待复核，各条只计一次，筛选不改变总统计。
