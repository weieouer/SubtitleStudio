# 换电脑恢复说明

> 当前目录是含 `runtime/python` 的便携版，完整解压后直接运行 `run.bat`，无需安装系统 Python。下面“不含环境”等说明描述历史源码迁移包；当前包是否包含模型与依赖，以实际目录为准。不要单独搬运 `.venv` 代替整个目录。Windows 文件/目录选择框已改用系统 API，不要求安装 Tcl/Tk；遇到失败看帮助 → 终端中的具体错误。

本包包含源码、README、历史文档、配置、已保存工程、识别结果、SRT 和找到的项目素材，不包含模型权重、主 .venv、data/engines 隔离虚拟环境、pip 缓存、日志、运行状态和波形缓存。

## 新电脑操作

1. 保留 SubtitleStudio 完整目录解压。先让助手读取 README.md、MIGRATION.json、requirements.txt、requirements-lock.txt 和本说明。
2. 原主环境为 Windows x64、Python 3.13.15，建议安装 Python 3.13 系列及 Chrome/Edge。双击 run.bat 重建依赖并启动；引擎依赖与安装源见 config/engines.json。主依赖固定版本在 requirements.txt；全部已安装依赖精确版本在 requirements-lock.txt 和 MIGRATION.json。
3. 模型需要重新下载。继续原工作优先 FireRedASR2-AED（约 4.5 GB，中文）或 Whisper large-v3（约 2.9 GB，多语言），方言素材可加 Qwen3-ASR-1.7B（约 3.5 GB），以及 Qwen3-ForcedAligner-0.6B（约 1.8 GB）；Silero VAD 随 faster-whisper 内置。模型仓库、隔离环境依赖声明记录在 MIGRATION.json 的 model_declarations。若新电脑网络受限，在原电脑把 `data/models` 整个复制到 U 盘，解压后放回同位置即可，目录名不需要改。
   - 首次联网需要下载：主 .venv 依赖约 340 MB（run.bat 自动安装）、qwen 引擎环境约 1.7 GB（界面下载对齐模型或点“配置环境”时安装）、上面列出的模型权重。`data/engines` 和 `.venv` 里的虚拟环境绑定了原电脑路径，不能直接复制。
4. Qwen 的独立环境声明为 qwen-asr==0.0.6 加 gradio<6（不加上限时 pip 会在 gradio 6.x 上反复回溯，极慢且可能失败）。FireRed 使用声明中的源代码地址；这些可选环境未安装时不能声称已锁定其全部间接依赖。qwen 的 nagisa 依赖经 DyNet 读模型，项目路径含中文时由 `patch_nagisa_model_path()` 自动复制模型到纯英文目录；安装后自检失败要先看这里。GPU 驱动、CUDA/PyTorch 版本要按新电脑硬件确认。
5. 修复旧工程路径后，再从顶部“打开项目”继续工作。需要同时修复工程 source_path/media_path、subtitle_file.path 和结果记录中的素材/字幕路径。先备份 JSON，不改字幕文字及时间。

## 给后续助手的路径迁移规则

- MIGRATION.json 的 original_root 是原电脑项目根目录。属于该根目录的绝对路径，替换成解压后 SubtitleStudio 的实际根目录，保留其相对后缀。
- external_assets 逐条给出项目外部素材 original_path 和包内 archive_path；把旧路径改成“新根目录 / archive_path”。外部视频已装入包内，不要求新电脑有原桌面路径。
- data/projects 文件名为 SHA1(os.path.abspath(素材或 SRT 路径).encode('utf-8')).hexdigest()[:16] + '.json'。改路径后需要重算文件名，避免项目加载找不到；冲突时先保留两份人工核对。
- missing_assets 列出了打包时不存在的外部素材，若非空则需要另行找到，不能冒充已经带走。
- 项目中的完整剧本、初始字幕、修改状态、模型配置均原样保留。新电脑首次启动可能执行默认参数迁移（提前出现和延后消失默认为 0 秒）。

## 版本记录和校验

MIGRATION.json 保存原环境、全部已安装包版本、模型声明、工程列表、外部素材映射及 files 中各文件的 SHA-256。模型和环境没有打包；这里只保留其版本和下载来源说明。

requirements-lock.txt 是原主环境快照，不保证其他 Python 版本或 CPU/GPU 平台所有二进制包都兼容。优先匹配原 Python 系列安装；遇到不兼容时应明确记录调整，不能静默声称完全复现。

历史 docs 报告是当时的快照，以当前 README、源码和迁移清单判断实现状态。原电脑聊天记录不是恢复工作的前提。
