### 1b. 2026-11-06 环境与下载相关修复

| 项 | 现象 | 处理 |
|---|---|---|

| 依赖装完仍报“引擎无法加载” | `nagisa` 用 DyNet 窄字符接口读模型，项目路径含中文（字幕工作室）时 `Could not read model from …` | `patch_nagisa_model_path()` 在 pip 后、自检前把 `nagisa_v001.model` 复制到 `%PUBLIC%\SubtitleStudio\nagisa\` 并改写 `nagisa/tagger.py`；纯英文路径不动。qwen 环境已验证 `ready.json` 与导入自检通过 |
| 模型目录名不一致 | 手动下载的权重目录名和清单名不同时，界面显示“未下载” | `model_directory()` 增加名称包含匹配（最长匹配优先）；新增 `POST /api/models/locate` 手动指定目录，映射写入 `data/models/.locations.json`，空 `path` 恢复默认。前端待接按钮：`/api/dialog`（`kind:"dir"`）→ `/api/models/locate` |
| 后台启动的重复进程 | 任务管理器中每次启动有两个 `pythonw.exe` | Windows venv 的 `pythonw.exe` 是重定向器，会再拉起基础解释器，属于正常现象，不是重复实例 |

### 1e. 2026-11-06 乱序剧本与复核修复

- 多剧本保留 source 身份、文件名、Unicode字符范围；独立来源游标支持乱序导入及跨文件返回，同文件内仍按台词顺序匹配。
- 普通尾部静音也记录显示封顶，不以裁剪量作为条件；全局底噪基准与局部低分位结合，不改写模型输入。
- 对齐错字用字符映射保留词时间；不可映射及重叠回退明确标错、清除过期词时间和停顿信息。
- 对齐台词不做ASR幻觉自动排除；导入SRT只提示可疑片尾口播。
- 分段继承可靠参考范围；不能继承的子条目及手动合并条目局部重匹配。
- 自动断句优先完整词语；模型逐字时间及词内静音不能拆完整词，只有词本身超限才允许词内硬切。连续无有效停顿、同原句的单字碎片可在字数允许时合回并覆盖完整时间。
- 音频PCM项目内有界缓存、剧本特征复用、按需组合；调整时间和设备设置避免重建全部字幕行。
- 唯一启动入口为 `run.bat`，删除只转调它的中文启动包装。打包方案按用户要求不处理。

证据及未完成边界见 [本轮实现报告](修复验证/乱序剧本与复核修复_2026-11-06/实现报告.md)。
