# 需求与规范

本文保留现行产品约束，界面参数名称与行为以此为准；历史完整描述在 [整合前档案](archive/文档整合前_2026-11-09/需求与规范.md)。

## 范围

本地中文字幕工作台，支持视频/音频、SRT、TXT/MD/DOCX 剧本。识别使用第一条音轨，不上传素材到云端。暂不提供翻译、烧录、声纹分离或多音轨选择；纯英文强制对齐未完成适配。模型在界面下载，不能强制用户一次准备全部模型。

## 版本与 Git 发布规则

版本统一为 `主版本.次版本.修复版本`，每次修改后发布的新包必须使用新的版本号，不能用旧号覆盖已经发布的包。

- 大功能或重大改版：主版本加 1，后两位归零，例如 `3.2.5 → 4.0.0`。
- 常规功能新增或改进：次版本加 1，末位归零，例如 `3.2.5 → 3.3.0`。
- 小问题修复：最后一位加 1，例如 `3.2.5 → 3.2.6`。
- 同一批修改按最高级别更新一次；版本号在后端、前端、帮助、包清单、文档和 EXE 文件名中保持一致。
- 每次发布先完成验证，再做 Git 提交并创建对应 `v主.次.修复` 标签，记录提交号与安装包 SHA256；需要交付 Git 时提供可恢复的 bundle。
- 旧版本提交、标签及安装包保留；未发布的中间构建不作为正式版本。当前桌面验收安装包为 `3.2.0`；未执行正式 Git 发布。

## 处理步骤

| 步骤 | 修改范围 | 无问题时标签（有问题时标黄/红） |
|---|---|---|
| 开始校验 | 对照参考标注内容差异；不改文字、时间或分段 | 校验通过 |
| 校准字幕 | 只用已定位的对应参考纠正文字差异；不自动增删条目、不拆分合并、不改时间；无可靠参考保留人工判断 | 校准通过 |
| 对齐字幕 | 用当前文字按音轨调整时间、时长和分段；只拆不合并，不改字词 | 对齐通过（仅无时间异常时） |

推荐顺序：识别或导入真实字幕 → 逐条反查剧本校验 → 校准文字 → 人工处理红色项 → 对齐音轨。剧本是第二轮文字参考，不是生成字幕的清单；不为未匹配的剧本内容生成空白字幕、缺句行或独立小窗口。内容有对应参考、只是错字、谐音、多字或漏字时为轻微问题（黄）；当前字幕没有可靠参考、上下文不符或不符合参数时为明显错误（红），保留人工处理，不自动变灰或排除。校验无问题显示校验通过，采用参考校准后显示校准通过，人工修改或确认显示修改通过；对齐无时间问题另显示对齐通过。筛选与实际标签一致。

文字通过不掩盖无效时间、真实对齐错误、异常长条或未解决的自动时间修复。仅因改字而过期的对齐记录不再让已确认内容重复标黄；需要对齐时仍可单独执行。异常时间不能计为成功对齐。参考定位结合前后句及再前一句的可靠锚点，重复台词只有在局部来源和顺序共同唯一时才采用，不能以全文其他位置的同句证明当前存在。

## 文本与参考

- 工作字幕、预览与导出统一简体中文，保留原 ASR、原时间和剧本原文。
- 剧本无固定人物/冒号格式要求，多份原文保留独立来源，不依赖导入顺序。
- 匹配以字面、拼音和上下文为证据，分数不是正确率；歧义、无参考或上下文不符要明确显示，不能仅凭同音自动改字。
- 换剧本清除旧建议及相关历史；文字变化后旧匹配/词时间失效。人工确认的文本不能被异步旧结果覆盖。
- 校准范围是勾选条目，未勾选时处理全部；只纠正有可靠对应参考的文字。分段和合并由对齐或用户单独执行，校准不恢复人工删行。
- “标点符号”开启只保留问号、感叹号和省略号，去掉逗号、句号等句读；关闭隐藏所有句读。数字内部点号、时间、百分号和英文词内连接不损坏。参考匹配及对齐拆句使用原参考的全部标点，不受显示开关影响。
- 当前字幕与右侧参考均可编辑，无参考时可直接补写；右侧补写保存在该条的人工参考字段，点击“采用此句”才修改当前字幕，保留原始识别与原文位置记录，支持保存及撤销。
- 人工参考随拆条按对应文字分配，拼接能恢复全文，不在每条重复整段；合并时保留全部人工参考。参考文字与字幕差异过大时提示拆分后复核。已采用且文字一致的人工参考，其标点也参与对齐断句。
- “阿拉伯数字”“字幕换行”统一作用于编辑显示、预览、波形文字与导出，不能破坏原始记录。
- 关闭“语气词”时，提取去除整条填充音和独立句首/句末语气词；导入或已有字幕中的整条语气词只标红，供人工处理。开启时允许保留；正常语法助词不按整条语气词处理。校准只采用可靠对应参考，不按此开关删除已有字幕。

## 时间与分段

- 每行字数、最短/最长时长等参数不符时标红；修改通过不能掩盖参数问题。
- 停顿阈值 0 表示关闭，短于阈值不拆；参考明确两句时按句界分开，不受停顿阈值影响。同一句的可靠参考对过度拆分有约束。
- 对齐不合并字幕；参考的两句话连着说时保持两条首尾衔接，过长条目再按每行字数拆分。
- RMS/VAD/字数时长用于保护发声边界。缺乏证据时保留原时间并提示复核；不为了满足经验时长裁掉对白。
- 原时间也异常且不能定位时停用词时间、暂停依赖这些词的分段，明确显示未能定位；不把保留结果算为成功。
- “对齐后时间微调”默认折叠；摘要显示未设置、已设置参数或预览中。收起时结束临时预览，不修改字幕或参数。
- 默认预览和导出均使用编辑区时间。提前/延后/最短/最长参数需点击“预览微调”才临时预览，常驻提示尚未应用；“应用到字幕”可撤销。可能截掉词音频、缩短却无可靠词时间或造成重叠时不应用。
- 分段不改文本顺序，不把子条拼到下一条原字幕；无可靠词时间的新时间标为估计。
- 字幕文字中光标两侧都有文字时按回车，从光标处分成两条；两侧空白与换行不保留，无可靠词时间的新时间标为估计并待复核。光标在首尾回车只结束编辑。文字中 Shift+回车插入换行，换行的显示按“字幕换行”开关统一处理。
- 手工移动/调整时间受到相邻条和媒体边界约束，内部及 SRT 保留毫秒精度。

## 编辑、保存与导出

- 合并只接受连续相邻多选，文字按原顺序拼接，时间取首尾范围；保留所有原始来源，整批可撤销。
- 添加必须先填写非空文字并有空余时间，取消不创建字幕；手工清空字幕后离开编辑框时移除空行，可撤销；删除针对勾选项；重置恢复本次导入/提取的初始字幕并可撤销。
- 全选包含被排除条目，不受搜索/筛选限制；勾选仅决定编辑范围，不改变导出标记。
- 问题标签只作标注，不自动关闭导出。旧自动幻觉排除解除，明确手动“不导出”的决定保留；修改与重新检查不能覆盖人工决定。
- SRT 导出 UTF-8 无 BOM、CRLF，使用编辑区实际起止时间；导出全部未被排除条目，不受选择和筛选影响。
- 无效时间、重叠或超出媒体范围阻止导出并提示；MKV 保留原视频、原音轨及独立字幕轨，不烧录、不重编码。
- 自动保存、Ctrl+S 与旧工程恢复保留完整编辑状态。冲突先备份再加载，断线能解除等待并重查原任务。
- 本地草稿按页面独立保存，仅在当前浏览器与地址下恢复；服务端确认保存后只清理对应版本，不删除其他页面或更新的草稿。恢复与服务器版本冲突时必须保留双方记录。
- 素材失联仍能打开、编辑、保存已有工程并导出 SRT；试听、识别和对齐需重新关联媒体。关联到已有工程的素材时先确认并备份。
- “保存工程”不等于导出 SRT；“打开工程文件夹”打开内部工程存储目录。导出成功后保留路径，提供定位文件与复制路径。

## 界面与反馈

- “推荐参数”面向中文短剧：自动设备、开启VAD、每行20字、停顿0.6秒、开启三类语气标点和换行、时间微调归零；保留语气词开关、模型、模式、数字风格、音量与主题，不下载环境，不改已有字幕。

- 左侧素材/模型参数，中间视频、字幕限制及波形，右侧字幕与对应参考；窄屏响应式排列。字幕限制放在视频下方、波形上方；预览文字上移只便于校对，不改变导出位置。预览收缩不能挤出时间轴和控件。
- 校对模式并排显示校验、校准、对齐；全选与选中数量放在条目列表左上，标签筛选包含轻微问题、明显错误、校验通过、校准通过、修改通过、对齐通过及未校验，不影响导出范围。
- 编辑工具两排排列，按钮文字完整、可聚焦，说明放在悬浮/聚焦提示；全选与选中提示放条目列表左上。
- 深浅主题使用统一 CSS 变量与层级；校验、校准、对齐自动通过用蓝，修改通过用绿，轻微问题用黄，明显错误用红。左右文字都按当前校验状态显示；不生成独立缺失参考行。内容通过来源与真实时间问题可同时显示。
- 点击字幕定位音轨，滚轮缩放、Shift+滚轮平移，播放跟随可切换；波形画法与幅度不改变实际音量。
- 长任务显示真实阶段/进度，可取消。处理中禁用冲突操作；异步响应必须校验当前工程和内容版本。
- Windows选择媒体、参考、SRT、模型目录和导出目录时，真实文件/文件夹选择框在初始化时置前；不只设置隐藏父窗口，不用定时器持续抢焦点。取消及错误退出后释放临时父窗口。
- 空格播放不能抢占按钮、输入框、视频或对话框的正常键盘操作。保留 Ctrl+S/Z/Y、搜索定位及逐条无障碍名称。
- 帮助使用一屏速查，只保留流程、标签与常用快捷键；常见桌面尺寸无需滚动，详细参数放控件提示。极小窗口保留溢出访问能力，不截掉操作。

真实对白、多人抢话、音乐/突发音效、语气词误删、GPU、DPI 和剪辑软件导入仍需实际素材验收；单元测试不能替代试听。
