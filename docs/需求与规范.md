# 需求与规范

本文保留现行产品约束，界面参数名称与行为以此为准；历史完整描述在 [整合前档案](archive/文档整合前_2026-11-09/需求与规范.md)。

## 范围

本地中文字幕工作台，支持视频/音频、SRT、TXT/MD/DOCX 剧本。识别使用第一条音轨，不上传素材到云端。暂不提供翻译、烧录、声纹分离或多音轨选择；纯英文强制对齐未完成适配。模型在界面下载，不能强制用户一次准备全部模型。

## 版本与 Git 发布规则

版本统一为 `主版本.次版本.修复版本`，每次修改后发布的新包必须使用新的版本号，不能用旧号覆盖已经发布的包。

- 大功能或重大改版：主版本加 1，后两位归零，例如 `3.2.5 → 4.0.0`。
- 常规功能新增或改进：次版本加 1，末位归零，例如 `3.2.5 → 3.3.0`。
- 小问题修复：最后一位加 1，例如 `3.2.5 → 3.2.6`。
- 同一批修改按最高级别更新一次；版本号在后端、前端、帮助、包清单、文档和 EXE 文件名中保持一致。
- 每次发布先完成验证，再做 Git 提交并创建对应 `v主.次.修复` 标签，记录提交号与安装包 SHA256；需要交付 Git 时提供可恢复的 bundle。
- 旧版本提交、标签及安装包保留；未发布的中间构建不作为正式版本。3.0.0 为字幕消除基线，本轮发布为 `3.1.0`。

## 三个处理步骤

“字幕消除”是独立的第一个模式，处理视频画面；原有字幕提取、校验/校准/对齐分工保留。框选区域内通过 PP-OCRv5 扫描全片的候选字幕时间段，右侧可定位、修改、删除、停用及手动补充；修改选区停用旧自动段。只处理启用时间段，空列表不能回退成全片修复。选区和时间段支持 Ctrl+Z，保存到独立工程配置，不覆盖字幕编辑状态。ProPainter 独立环境按需准备；短片预览无音轨，完整输出保留原音轨，原视频不覆盖。

| 步骤 | 修改范围 | 自动处理标签 |
|---|---|---|
| 开始校验 | 对照参考标注内容差异；不改文字、时间或分段 | 参考一致 |
| 校准字幕 | 按可靠参考修正内容、补漏/去冗、按句界和字数整理分段；不碰音轨 | 已校准 |
| 对齐字幕 | 用当前文字按音轨调整时间、时长和分段；只拆不合并，不改字词 | 自动对齐完成 |

推荐顺序：校验 → 校准 → 对齐。自动完成不代表人工确认。文字确认只覆盖内容疑点；无效时间、对齐错误、过期对齐、异常长条和自动时间修复在各阶段都保持可见，仍进入待复核筛选和报告。异常时间不能计为成功对齐。

## 文本与参考

- 工作字幕、预览与导出统一简体中文，保留原 ASR、原时间和剧本原文。
- 剧本无固定人物/冒号格式要求，多份原文保留独立来源，不依赖导入顺序。
- 匹配以字面、拼音和上下文为证据，分数不是正确率；歧义、无参考或上下文不符要明确显示，不能仅凭同音自动改字。
- 换剧本清除旧建议及相关历史；文字变化后旧匹配/词时间失效。人工确认的文本不能被异步旧结果覆盖。
- 校准范围是勾选条目，未勾选时处理全部；不跨未选条目或手动分段边界合并。可靠参考明确为两句时分开，同句合并需满足宽度、停顿及导出状态约束；其余碎片只提示“建议合并”。
- “标点符号”开启保留问号/感叹号，关闭隐藏其余标点；数字内部点号、时间、百分号和英文词内连接不损坏。校准只从可靠参考恢复语气标点。
- “阿拉伯数字”“字幕换行”统一作用于编辑显示、预览、波形文字与导出，不能破坏原始记录。
- 关闭“语气词”时按规则去除整条填充音及句首/句末独立语气词；保留语法助词和受保护的人工决定。开启时也不能保留可靠参考明确没有的多余语气词。

## 时间与分段

- 停顿阈值 0 表示关闭，短于阈值不拆；参考明确两句时按句界分开，不受停顿阈值影响。同一句的可靠参考对过度拆分有约束。
- 对齐不合并字幕；参考的两句话连着说时保持两条首尾衔接，过长条目再按每行字数拆分。
- RMS/VAD/字数时长用于保护发声边界。缺乏证据时保留原时间并提示复核；不为了满足经验时长裁掉对白。
- 原时间也异常且不能定位时停用词时间、暂停依赖这些词的分段，明确显示未能定位；不把保留结果算为成功。
- 默认预览和导出均使用编辑区时间。提前/延后/最短/最长参数需点击“预览微调”才临时预览，常驻提示尚未应用；“应用到字幕”可撤销。可能截掉词音频、缩短却无可靠词时间或造成重叠时不应用。
- 分段不改文本顺序，不把子条拼到下一条原字幕；无可靠词时间的新时间标为估计。
- 手工移动/调整时间受到相邻条和媒体边界约束，内部及 SRT 保留毫秒精度。

## 编辑、保存与导出

- 合并只接受连续相邻多选，文字按原顺序拼接，时间取首尾范围；保留所有原始来源，整批可撤销。
- 添加必须有空余时间；删除针对勾选项；重置恢复本次导入/提取的初始字幕并可撤销。
- 全选包含被排除条目，不受搜索/筛选限制；勾选仅决定编辑范围，不改变导出标记。
- 问题标签只作标注，不自动关闭导出。手动关闭导出、已确认幻觉的排除保留；修改与重新检查不能覆盖人工决定。
- SRT 导出 UTF-8 无 BOM、CRLF，使用编辑区实际起止时间；导出全部未被排除条目，不受选择和筛选影响。
- 无效时间、重叠或超出媒体范围阻止导出并提示；MKV 保留原视频、原音轨及独立字幕轨，不烧录、不重编码。
- 自动保存、Ctrl+S 与旧工程恢复保留完整编辑状态。冲突先备份再加载，断线能解除等待并重查原任务。
- “保存工程”不等于导出 SRT；“打开工程文件夹”打开内部工程存储目录。导出成功后保留路径，提供定位文件与复制路径。

## 界面与反馈

- 左侧参数/素材，中间视频/波形，右侧字幕与对应参考；窄屏响应式排列。竖屏保留比例，预览收缩不能挤出时间轴和控件。
- 编辑工具两排排列，按钮文字完整、可聚焦，说明放在悬浮/聚焦提示；全选与选中提示放标题行。
- 深浅主题使用统一 CSS 变量与层级；自动完成用蓝、人工文字确认用绿，疑似用黄，明显问题及建议合并用红。文字确认与时间问题可同时显示。
- 点击字幕定位音轨，滚轮缩放、Shift+滚轮平移，播放跟随可切换；波形画法与幅度不改变实际音量。
- 长任务显示真实阶段/进度，可取消。处理中禁用冲突操作；异步响应必须校验当前工程和内容版本。
- 空格播放不能抢占按钮、输入框、视频或对话框的正常键盘操作。保留 Ctrl+S/Z/Y、搜索定位及逐条无障碍名称。
- 帮助使用一屏速查，只保留流程、标签与常用快捷键；常见桌面尺寸无需滚动，详细参数放控件提示。极小窗口保留溢出访问能力，不截掉操作。

真实对白、多人抢话、音乐/突发音效、语气词误删、GPU、DPI 和剪辑软件导入仍需实际素材验收；单元测试不能替代试听。
